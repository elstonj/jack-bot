**Context:** Vantor (GPS-denied positioning company) proposed ~$60K custom development for sub-meter accuracy with standardized video geospatial tagging. Jack identified this as excessive scope; team pivoted to phased validation approach.

**Discussion Flow:**
1. **Oct 30, 16:21-16:30** – Jack flagged that custom video tagging solution (~$60K development) duplicates existing workaround patterns; proposed alternative using RTK-fed FLIR Vue Pro R with existing S3 volcano payload for rapid validation.

2. **Oct 30, 16:26-16:36** – Maciej clarified that Vantor is receptive to photogrammetry/photo-based data validation approach; suggested using existing Hawaii volcano dataset rather than new field collection. 3. **Oct 30, 16:32-17:31** – Jack and Maciej refined strategy: Vantor has internal photogrammetry tooling (uncertain if drone-capable) and wants to compare predicted image poses against ground-truth geospatial tags for validation accuracy. Photogrammetry correction can substitute for native RTK if dataset quality sufficient. Jack created presentation deck for team/Vantor review.

4. **Oct 30, 19:50-20:51** – Maciej added geographic/seasonal context: Vantor holds thermal dataset over Swedish test farm; interested in expanding to urban/suburban scenes and anomalous thermal features (especially volcano data). Winter building thermal signatures valuable for heating system validation. CU campus flights possible under existing blanket COA. Jack noted LLM-assisted presentation generation improving deck quality and turnaround time.

**Outcome:**
- Presentation deck created (link shared Oct 30, 17:31)
