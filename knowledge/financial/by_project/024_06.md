# Project 024-06 — Financial Summary

## Project Overview

**Full Project Name:** Runway Integrity Validation through Soil Moisture Measurements from a Small UAS (Soil Moisture Mapping Phase II, Project X22.4)

**Client/Agency:** Department of Air Force (DAF)

**Contract Type:** SBIR Phase II

**Period of Performance:** Data available 2024-06 through 2026-08 (QuickBooks shows activity through 2025-09, with final entry 2026-08 at $0.00)

**Brief Description of Scope:** 
This SBIR Phase II project focuses on developing and validating UAS-based soil moisture measurement capabilities for runway integrity assessment. The work involves integration of L-band radiometer, thermal, and NDVI sensors into a modular payload for BST's E2 UAS platform. Milestone 3 (completed June 2024) achieved sensor integration and preliminary field validation. The project is progressing toward Milestone 4 algorithm development for soil integrity calculation.
