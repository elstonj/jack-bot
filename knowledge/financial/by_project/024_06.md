# Project 024-06 — Financial Summary

## Project Overview

**Project Code:** 024-06

**Primary Project:** Runway Integrity Validation through Soil Moisture Measurements from a Small UAS (SMM Phase II 22.4D)

**Client/Agency:** Department of Air Force (DAF)

**Program/Solicitation:** AFWERX SBIR Phase II – Soil Moisture Mapping (Project X22.4)

**Contract Type:** SBIR Phase II

**Brief Description:** Integration of L-band radiometer with thermal and NDVI sensors on BST's E2 UAS platform for soil integrity validation. Work includes sensor payload design, field testing, and algorithm development for soil integrity calculation. The project also encompasses related activities including S2 methane leak detection development (with Quanta3 LLC) and various other government/commercial sensor integration projects.

## Key Deliverables & Milestones

**Source:** Proposals & Reports (Milestone #3 Report dated 2024-06-11)

### Primary Project: SMM Phase II 22.4D (AFWERX SBIR Phase II)

**Milestone #3 (Completed as of 2024-06):**
- Selection, procurement, design, and testing of thermal and NDVI sensors
- Integration into self-contained bolt-on module for E2 UAS
- Preliminary field testing validating sensor performance
- Antenna redesign (2×2 patch array) using air-sandwich dielectric
- Single data logging point integration (eliminated Raspberry Pi/USB hub)

**Milestone #4 (In Progress):**
- Algorithm development for soil integrity calculation from radiometer, NDVI, and thermal data

**Technical Scope:**
- L-band radiometer integration with E2 UAS platform
- NDVI sensor (SDI-12 protocol, 2-second update cycle)
- Thermal sensor (I2C protocol, near-instantaneous updates)
- Modular payload architecture
- Reduced cost/complexity vs. baseline design
