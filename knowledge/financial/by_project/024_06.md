# Project 024-06 — Financial Summary

## Project Overview
**Project Code:** 024-06

**Primary Project:** Runway Integrity Validation through Soil Moisture Measurements from a Small UAS (Soil Moisture Mapping Phase II – Project X22.4)

**Client/Agency:** Department of Air Force (DAF)

**Contract Type:** SBIR Phase II

**Period of Performance:** Data available 2024-06 through 2025-11 (from QuickBooks actuals); Milestone #3 report dated 2024-06-11

**Brief Description:** BST is developing an integrated sensor system (L-band radiometer with thermal and NDVI sensors) mounted on the E2 UAS platform for runway soil integrity validation. The system uses multi-spectral measurements to calculate soil moisture and validate runway conditions. Work includes sensor integration, design optimization, field testing, and algorithm development across multiple milestones.
