# Project 026-06 — Financial Summary

## Project Overview
- **Full Project Name:** S0 Expendable UAS for Navy Maritime Weather Observations (Phase I Option Period)
- **Client/Agency:** Department of the Navy
- **Contract Type:** SBIR Phase I Option Period
- **Program/Solicitation:** BAA topic N25A-T025; "Expendable Air-sea Profiling Observations in Hazardous Weather Conditions"
- **Period of Performance:** March 20, 2026 – June 3, 2026 (initial reporting period; Phase I Option revised and approved at kickoff)
- **Brief Description of Scope:** Development and validation of the S0 uncrewed aircraft system (UAS) and S0-VTOL variant for high-resolution atmospheric and ocean-surface profiling data in hazardous Navy maritime weather conditions. Focus areas include calibration/validation planning, icing capability design, stakeholder integration, and validation analysis using NOAA oceanic flight data.
