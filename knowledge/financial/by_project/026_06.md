# Project 026-06 — Financial Summary

## Project Overview
- **Full Project Name:** S0 Expendable UAS Platform for Navy Maritime Weather Observations (SBIR Phase I Option Period)
- **Client/Agency:** Department of the Navy
- **Contract Type:** SBIR/STTR Phase I Option Period
- **Program/Solicitation:** BAA topic N25A-T025; "Expendable Air-sea Profiling Observations in Hazardous Weather Conditions"
- **Period of Performance:** March 20, 2026 – June 3, 2026 (initial reporting period); broader contract spans multiple phases
- **Brief Description of Scope:** Development and validation of the S0 uncrewed aircraft system (UAS), including S0-VTOL (vertical take-off and landing variant), for high-resolution atmospheric and ocean-surface profiling data in hazardous maritime conditions. Focus areas include calibration/validation, icing capability design, stakeholder integration planning, and onboard algorithm development.
