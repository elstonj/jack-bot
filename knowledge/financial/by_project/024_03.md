# PROJECT 024-03 — FINANCIAL SUMMARY

## Project Overview
- **Full Project Name**: "On-demand wildfire susceptibility from fuel moisture and vegetative index maps"
- **Client/Agency**: NASA (ROSES 2024, A.59 funding opportunity)
- **Contract Type**: NASA ROSES research grant (Step 2 submission)
- **Period of Performance**: April 1, 2025 – April 1, 2028 (3-year extended period)
- **Brief Description**: Multi-partner research project to develop soil moisture and live fuel moisture mapping capabilities using small UAS platforms, NISAR satellite data, and UAVSAR to support wildfire susceptibility assessment. Project involves field validation campaigns at Pepperwood Preserve and Weather Stream data processing operations.
