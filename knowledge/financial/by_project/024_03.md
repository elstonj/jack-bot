- **Full Project Name**: "On-demand wildfire susceptibility from fuel moisture and vegetative index maps"

## Key Deliverables & Milestones

**Data from OSDMP and Proposal Documents**

### Technical Deliverables
1. **Small UAS Soil Moisture Maps**
   - 192 flights per year generating 2m resolution soil moisture maps
   - 10GB HDF data files annually
   - Integration with NISAR and UAVSAR products

2. **Live Fuel Moisture (LFM) Product**
   - Vegetative index maps for wildfire susceptibility assessment
   - Developed using satellite and UAS soil moisture inputs
   - Code in IDL and Python

3. **NISAR Integration (Year 1 onwards, starting October 2025)**
   - 200m resolution satellite soil moisture maps
   - 6-day repeat interval
   - 6GB HDF data annually

4. **UAVSAR Flights (Year 1)**
   - 9 planned flights
   - 6m resolution SAR soil moisture products

5. **Data & Software Release**
   - All data to be archived and published publicly upon validation
   - Operational processing codes to be released at project completion (April 2028)
   - Open Science and Data Management Plan (OSDMP) compliance

- **Year 1 (Apr 2025 – Mar 2026)**: System setup, initial UAS flights, UAVSAR campaigns, NISAR prep
- **Year 2 (Apr 2026 – Mar 2027)**: Continued UAS operations, NISAR data integration, algorithm refinement
- **Year 3 (Apr 2027 – Apr 2028)**: Extended Weather Stream operations, final data archiving, public release
