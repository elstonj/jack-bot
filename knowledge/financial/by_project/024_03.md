# Project 024-03 — Financial Summary

## Project Overview
- **Full Project Name**: "On-demand wildfire susceptibility from fuel moisture and vegetative index maps"
- **Client/Agency**: NASA (ROSES 2024, Topic A.59 funding opportunity)
- **Contract Type**: NASA ROSES research grant (Step 2 submission)
- **Period of Performance**: April 1, 2025 – April 1, 2028 (3-year period, with extended Weather Stream component through April 1, 2028)
- **Brief Description of Scope**: Multi-partner research project integrating small UAS remote sensing, satellite data (NISAR, UAVSAR), and field validation campaigns to generate on-demand wildfire susceptibility maps using soil moisture and live fuel moisture data. Project includes 192 UAS flights/year, field sampling at Pepperwood Reserve, data processing and algorithm development, and public data archival.
