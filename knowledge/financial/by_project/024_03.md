# Project 024-03 — Financial Summary

## Project Overview
- **Full Project Name**: "On-demand wildfire susceptibility from fuel moisture and vegetative index maps"
- **Client/Agency**: NASA
- **Program/Solicitation**: ROSES 2024, Topic A.59
- **Contract Type**: NASA ROSES research grant (Step 2 submission)
- **Period of Performance**: April 1, 2025 – April 1, 2028 (3 years)
- **Brief Description of Scope**: Multi-partner research project to develop wildfire susceptibility assessment capabilities using soil moisture and live fuel moisture (LFM) mapping. Integrates small UAS platform (providing 2m resolution soil moisture maps), NISAR satellite data (200m resolution, 6-day repeat), and UAVSAR (6m resolution). Project involves 9 field validation campaigns at Pepperwood Reserve with data synthesis and operational algorithm development in IDL and Python. Partners include Black Swift Technologies (prime), Pepperwood Reserve, Weather Stream, Orbital Micro Systems, JPL/Caltech, and USGS.
