# Project 024-03 — Financial Summary

## Project Overview
- **Full Project Name**: "On-demand wildfire susceptibility from fuel moisture and vegetative index maps"
- **Client/Funding Agency**: NASA (ROSES 2024, A.59 funding opportunity)
- **Contract Type**: NASA ROSES research grant (Step 2 submission)
- **Period of Performance**: April 1, 2025 – April 1, 2028 (3 years)
- **Brief Description**: Multi-partner research project to develop soil moisture and live fuel moisture mapping capabilities using small UAS platforms, satellite data (NISAR, UAVSAR), and field validation campaigns. Integrates data from Pepperwood Preserve field site with Weather Stream aerial platform operations.
