# Project 024-03 — Financial Summary

## Project Overview

**Project Title:** "On-demand wildfire susceptibility from fuel moisture and vegetative index maps"

**Funding Agency/Client:** NASA ROSES 2024 (A.59 funding opportunity)

**Contract Type:** NASA ROSES research grant (Step 2 submission)

**Period of Performance:** April 1, 2025 – April 1, 2028 (3 years)

**Brief Description of Scope:**  
A multi-partner research project led by Black Swift Technologies (BST) in collaboration with Pepperwood and Weather Stream partners. The project develops on-demand wildfire susceptibility mapping by integrating small UAS-derived soil moisture and live fuel moisture maps with NISAR satellite and UAVSAR data. Key activities include 192 small UAS flights annually, field validation campaigns at Pepperwood preserve (9 campaigns/year), data processing and synthesis, and operational code development in IDL and Python. Data and codes will be released publicly upon validation and project completion.
