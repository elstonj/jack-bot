# Project 024-03 — Financial Summary

## Project Overview
- **Full Project Name**: "On-demand wildfire susceptibility from fuel moisture and vegetative index maps"
- **Client/Agency**: NASA (ROSES 2024 A.59 funding opportunity)
- **Contract Type**: NASA ROSES research grant (Step 2 submission)
- **Period of Performance**: April 1, 2025 – April 1, 2028 (3-year extended period)
- **Brief Description of Scope**: Multi-institutional research project to develop wildfire susceptibility mapping using fuel moisture and vegetative index data from small UAS platforms, satellite (NISAR, UAVSAR), and field validation campaigns. Primary partners include Pepperwood (field validation, research) and Weather Stream (aerial data collection and processing).
