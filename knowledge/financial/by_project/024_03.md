# Project 024-03 — Financial Summary

## Project Overview
- **Full Project Name**: "On-demand wildfire susceptibility from fuel moisture and vegetative index maps"
- **Client/Agency**: NASA (ROSES 2024, Topic A.59)
- **Contract Type**: NASA ROSES research grant (Step 2 submission)
- **Period of Performance**: April 1, 2025 – April 1, 2028 (3-year extended period)
- **Brief Description**: Multi-partner research project integrating small UAS, NISAR satellite, and UAVSAR platforms to generate high-resolution soil moisture and live fuel moisture maps for wildfire susceptibility assessment. Project involves field validation campaigns at Pepperwood Reserve and remote sensing data processing.
