# Project 024-03 — Financial Summary

## Project Overview

**Full Project Name:** "On-demand wildfire susceptibility from fuel moisture and vegetative index maps"

**Client/Agency:** NASA (ROSES 2024, A.59 funding opportunity)

**Contract Type:** NASA ROSES research grant (Step 2 submission)

**Period of Performance:** April 1, 2025 – April 1, 2028 (3-year extended period)

**Brief Description of Scope:**
A collaborative research project integrating data from small UAS platforms, NISAR satellite, and UAVSAR to generate soil moisture and live fuel moisture (LFM) maps for wildfire susceptibility assessment. The project involves field validation campaigns at Pepperwood Preserve, data processing, and open science data archival. Key partners include Pepperwood Preserve and Weather Stream (sensor/data partners). The project supports fire management agencies with on-demand fuel moisture and vegetative index products.
