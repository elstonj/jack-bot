# PROJECT CODE 024-03 — FINANCIAL SUMMARY

## Project Overview

**Project Title:** "On-demand wildfire susceptibility from fuel moisture and vegetative index maps"

**Client/Agency:** NASA (ROSES 2024, A.59 funding opportunity)

**Contract Type:** NASA ROSES research grant (Step 2 submission)

**Period of Performance:** April 1, 2025 – April 1, 2028 (3 years)

**Brief Description of Scope:**
A multi-partner research project focused on developing soil moisture and live fuel moisture mapping capabilities using small UAS platforms, satellite data (NISAR, UAVSAR), and ground validation campaigns. The project includes field validation at Pepperwood Preserve and data processing/systems integration through Weather Stream partner. Deliverables include soil moisture maps, live fuel moisture products, and operational codes for wildfire susceptibility assessment.
