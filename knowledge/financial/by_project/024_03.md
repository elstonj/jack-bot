# Project 024-03 — Financial Summary

## Project Overview
- **Full Project Name**: "On-demand wildfire susceptibility from fuel moisture and vegetative index maps"
- **Client/Agency**: NASA (ROSES 2024, A.59 funding opportunity)
- **Contract Type**: NASA ROSES research grant (Step 2 submission)
- **Period of Performance**: April 1, 2025 – April 1, 2028 (3 years)
- **Brief Description**: Multi-partner research project combining field validation campaigns (Pepperwood Partner) and aerial/satellite data collection and processing (Weather Stream Partner) to map soil moisture and live fuel moisture for wildfire susceptibility assessment. Project integrates small UAS platforms, NISAR satellite data, and UAVSAR with ground-truth field sampling across 9 planned field campaigns.

### Project Deliverables (from OSDMP)

1. **Soil Moisture Maps (2m resolution)** — Generated from small UAS flights; 192 flights/year producing 10GB data annually
2. **Live Fuel Moisture (LFM) Maps** — Derived from field validation campaigns and satellite integration
3. **Wildfire Susceptibility Products** — Integrated analysis combining fuel moisture and vegetative indices
4. **Open Science Data Archive** — All data to be shared publicly upon validation (no cost impact; support service)
5. **Operational Processing Codes** — IDL and Python codes to be released at project completion (no cost impact)

- Field campaign costs (personnel, lodging, fuel, supplies) will be incurred evenly across 3 years
- No major capital equipment purchases beyond the $1,000 bench scale and $200 pruners in Year 1
- Data processing is primarily labor-intensive (Weather Stream personnel allocation)
- No cost overruns anticipated based on proposed budget structure
