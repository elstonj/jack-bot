# Project 024-03 — Financial Summary

## Project Overview
- **Project Title**: "On-demand wildfire susceptibility from fuel moisture and vegetative index maps"
- **Client/Agency**: NASA (ROSES 2024, Topic A.59)
- **Contract Type**: NASA ROSES research grant (Step 2 submission)
- **Period of Performance**: April 1, 2025 – April 1, 2028 (3 years)
- **Brief Scope**: Multi-partner research project integrating small UAS, NISAR satellite, and UAVSAR data for soil moisture and live fuel moisture mapping to support wildfire susceptibility analysis. Project involves field validation campaigns at Pepperwood Reserve and weather station data integration via Weather Stream partner.

**Data Source Note**: Project appears to be in proposal/planning phase. Budget docs dated March 2024 indicate Step 2 NASA submission. Proposal document was archived in "Attic" folder, suggesting possible non-submission or inactive status as of documentation date.
