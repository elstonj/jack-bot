# Project 024-03 — Financial Summary

## Project Overview
- **Full Project Name**: "On-demand wildfire susceptibility from fuel moisture and vegetative index maps"
- **Client/Agency**: NASA (ROSES 2024, A.59 funding opportunity)
- **Contract Type**: NASA ROSES research grant (Step 2 submission)
- **Period of Performance**: April 1, 2025 – April 1, 2028 (3 years)
- **Brief Description of Scope**: Multi-partner research project combining field validation campaigns at Pepperwood Preserve with remote sensing data integration (small UAS, NISAR satellite, UAVSAR) to map soil moisture and live fuel moisture for wildfire susceptibility assessment. Includes 9 field campaigns annually, 192 UAS flights per year, and integration with satellite-based SAR data beginning October 2025.
