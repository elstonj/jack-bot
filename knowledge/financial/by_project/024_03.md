# Project 024-03 — Financial Summary

## Project Overview
- **Full Project Name**: "On-demand wildfire susceptibility from fuel moisture and vegetative index maps"
- **Client/Agency**: NASA (ROSES 2024, A.59 funding opportunity)
- **Contract Type**: NASA ROSES research grant (Step 2 submission)
- **Period of Performance**: April 1, 2025 – April 1, 2028 (3 years)
- **Brief Description**: Multi-partner research project integrating small unmanned aircraft systems (UAS), satellite data (NISAR, UAVSAR), and ground field validation to generate on-demand wildfire susceptibility maps using fuel moisture and vegetative indices. Primary field validation site: Pepperwood Preserve, CA.
