# Project 024-03 — Financial Summary

## Project Overview
- **Full Project Name**: "On-demand wildfire susceptibility from fuel moisture and vegetative index maps"
- **Client/Agency**: NASA (ROSES 2024, A.59 funding opportunity)
- **Contract Type**: NASA ROSES research grant (Step 2 submission)
- **Period of Performance**: April 1, 2025 – April 1, 2028 (3 years)
- **Brief Description**: Multi-partner research project combining small UAS-based soil moisture mapping, satellite data (NISAR, UAVSAR), and field validation campaigns to generate on-demand wildfire susceptibility products. Primary partners: Pepperwood (field validation), Weather Stream (aerial data collection), and Black Swift Technologies (overall coordination, systems).
