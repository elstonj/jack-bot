# Project 024-03 — Financial Summary

## Project Overview

**Project Title:** "On-demand wildfire susceptibility from fuel moisture and vegetative index maps"

**Client/Agency:** NASA ROSES 2024 (A.59 funding opportunity)

**Contract Type:** NASA ROSES research grant (Step 2 submission)

**Period of Performance:** April 1, 2025 – April 1, 2028 (3-year extended period)

**Brief Description of Scope:**  
Multi-institution collaborative research project combining field validation campaigns, small UAS soil moisture mapping (192 flights/year), satellite data integration (NISAR, UAVSAR), and live fuel moisture modeling to produce on-demand wildfire susceptibility maps. Partners include Pepperwood (field validation lead) and Weather Stream (aerial platform operations and data processing). Project integrates ground-based field sampling with remote sensing to improve fire management decision support.
