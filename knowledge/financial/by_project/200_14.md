# Project 200-14 — Financial Summary

## Project Overview
- **Project Name:** [200-14] Autonomy
- **Full Title:** Adaptive and Secure Autonomy for UAS: A Modular Approach to Flight Control, Machine Learning Integration, and Multi-Vehicle Coordination
- **Client/Agency:** NASA (Shared Services Center, Stennis Space Center, Mississippi)
- **Principal Investigator:** Dr. Jack Elston
- **Contract Type:** SBIR Phase I
- **Contract Number:** 80NSSC25C0155
- **Period of Performance:** September 29, 2025 – March 27, 2026 (6 months)
- **Project Status:** **ARCHIVED & COMPLETE** — Final payment received April 16, 2026; project closed
- **Brief Description:** Phase I R&D effort to develop and validate a modular, layered architecture for SwiftCore avionics enabling autonomous flight control. Work included architecture definition, SwiftCore firmware/software updates (4.0 SBC and RTOS Autopilot board), ML-based automatic PID controller tuning, safe sandbox framework for external control modules, and comprehensive validation through benchtop simulations, bench tests, and flight tests. All four technical milestones completed and all financial deliverables invoiced by project end.
