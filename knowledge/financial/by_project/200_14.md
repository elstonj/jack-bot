# Project 200-14 — Financial Summary

## Project Overview
- **Full Project Name:** Adaptive and Secure Autonomy for UAS: A Modular Approach to Flight Control, Machine Learning Integration, and Multi-Vehicle Coordination
- **Client/Agency:** NASA (Shared Services Center, Stennis Space Center, MS)
- **Contract Type:** SBIR Phase I
- **Contract Number:** 80NSSC25C0155
- **Period of Performance:** September 29, 2025 – March 27, 2026 (6 months)
- **Project Status:** **ARCHIVED & COMPLETE** (Final payment received April 16, 2026)
- **Team:** Dan Prendergast (Owner), Dr. Jack Elston (PI), Dr. Maciej Stachura (CTO), Ben Busby, Meredith O'Hara Needham

**Brief Description of Scope:**  
Phase I R&D effort to develop and validate a modular, layered architecture for SwiftCore avionics enabling UAS autonomy. Deliverables included: (1) layered architecture definition and pub/sub messaging protocol specification; (2) SwiftCore system adaptation (4.0 SBC and RTOS Autopilot board); (3) safe sandbox framework for experimental control modules; (4) ML-enabled automatic PID controller tuning proof-of-concept; and (5) validation via benchtop simulations, bench tests, and flight tests. Technical output disclosed to NASA via iEdison (New Technology Summary Report, March 26, 2026).
