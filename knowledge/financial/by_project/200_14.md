# Project 200-14 — Financial Summary

## Project Overview
- **Full Project Name:** Adaptive and Secure Autonomy for UAS: A Modular Approach to Flight Control, Machine Learning Integration, and Multi-Vehicle Coordination
- **Client/Agency:** NASA (Shared Services Center, Stennis Space Center, Mississippi)
- **Contract Type:** SBIR Phase I
- **Contract Number:** 80NSSC25C0155
- **Principal Investigator:** Dr. Jack Elston, Black Swift Technologies LLC
- **Period of Performance:** September 29, 2025 – March 27, 2026 (6 months)
- **Project Status:** **ARCHIVED** — All work completed and final payment received; project closure completed April 16, 2026
- **Brief Description:** Development of a modular, layered architecture for SwiftCore avionics enabling autonomous flight control with machine learning-based sensing/control, multi-vehicle coordination, safe sandbox framework for experimental modules, and integrated plugin architecture. Technical achievements include 5-layer functional architecture with pub/sub messaging, ML terrain-following module with automated PID tuning, successful flight and bench testing, JSBSim integration, and supervisory controller with safety thresholds.
