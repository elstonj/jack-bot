# Project 200-14 — Financial Summary

## Project Overview
- **Full Project Name:** Adaptive and Secure Autonomy for UAS: A Modular Approach to Flight Control, Machine Learning Integration, and Multi-Vehicle Coordination
- **Client/Agency:** NASA (Shared Services Center, Stennis Space Center, Mississippi)
- **Contract Type:** SBIR Phase I
- **Contract Number:** 80NSSC25C0155
- **Principal Investigator:** Dr. Jack Elston
- **Period of Performance:** September 29, 2025 – March 27, 2026 (6 months)
- **Project Status:** **ARCHIVED** — All work completed successfully. Final administrative tasks and payment received completed April 16, 2026.

**Brief Description of Scope:**  
Develop modular, layered architecture for SwiftCore avionics system enabling aircraft autonomy with multi-vehicle coordination and machine learning-based sensing/control. Technical achievements include: 5-layer functional architecture with pub/sub messaging, ML module for terrain-following flight with automated PID tuning, safe sandbox framework, plugin architecture integration, supervisory controller with safety thresholds, JSBSim simulation integration, and successful flight/bench testing.
