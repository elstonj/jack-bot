# Project 200-14 — Financial Summary

## Project Overview
- **Full Project Name:** Adaptive and Secure Autonomy for UAS: A Modular Approach to Flight Control, Machine Learning Integration, and Multi-Vehicle Coordination
- **Client/Agency:** NASA (Shared Services Center, Stennis Space Center, MS)
- **Contract Type:** SBIR Phase I
- **Contract Number:** 80NSSC25C0155
- **Principal Investigator:** Dr. Jack Elston, Black Swift Technologies LLC
- **Period of Performance:** September 29, 2025 – March 27, 2026 (6 months)
- **Project Status:** **ARCHIVED** — All work completed successfully; project closed April 16, 2026

**Brief Scope Description:**  
Develop modular, layered architecture for SwiftCore avionics system enabling UAS autonomy with multi-vehicle coordination, machine learning-based sensing/control, and a safe sandbox framework for experimental control modules. Project delivered 5-layer functional architecture, ML terrain-following module, supervisory controller, and comprehensive technical documentation.
