# Project 200-14 — Financial Summary

## Project Overview
- **Full Project Name:** Adaptive and Secure Autonomy for UAS: A Modular Approach to Flight Control, Machine Learning Integration, and Multi-Vehicle Coordination
- **Client/Agency:** NASA / Shared Services Center (Stennis Space Center, Mississippi)
- **Contract Type:** Small Business Innovation Research (SBIR) Phase I
- **Contract Number:** 80NSSC25C0155
- **Principal Investigator:** Dr. Jack Elston, Black Swift Technologies LLC
- **Period of Performance:** September 29, 2025 – March 27, 2026 (6 months)
- **Project Status:** **ARCHIVED** — All work completed; final administrative tasks closed April 16, 2026

**Brief Description of Scope:**  
Development of a modular, layered architecture for SwiftCore avionics system enabling aircraft autonomy through multi-vehicle coordination, machine learning-based sensing and control, safe sandbox frameworks for experimental modules, and supervisory controller systems with safety thresholds. Project delivered 5-layer functional architecture, terrain-following ML module with automated PID tuning, plugin architecture integration, and successful flight/bench test validation.
