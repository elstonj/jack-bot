# Project 200-14 — Financial Summary

## Project Overview
- **Full Project Name:** Adaptive and Secure Autonomy for UAS: A Modular Approach to Flight Control, Machine Learning Integration, and Multi-Vehicle Coordination
- **Client/Agency:** NASA (Stennis Space Center, Mississippi)
- **Contract Type:** SBIR Phase I
- **Contract Number:** 80NSSC25C0155
- **Period of Performance:** September 29, 2025 – March 27, 2026 (6 months)
- **Project Status:** **ARCHIVED & COMPLETE** (Final payment received April 16, 2026; project closed)
- **Principal Investigator:** Dr. Jack Elston, Black Swift Technologies LLC
- **Technical POC:** Jinu Idicula (NASA, 661-276-2892); Billing POC: James Hibbs (NASA)

**Scope:** Phase I R&D effort to develop and validate a modular, layered architecture for SwiftCore avionics enabling aircraft autonomy. Work included architecture definition, messaging protocol specification, SwiftCore system adaptation (4.0 SBC and RTOS Autopilot board), safe sandbox development for external control modules, and ML-enabled control loop tuning. Validation conducted via benchtop simulations, bench tests, and flight tests. New technology disclosed to NASA via iEdison.
