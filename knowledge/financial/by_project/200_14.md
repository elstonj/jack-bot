# Project 200-14 — Financial Summary

## Project Overview
- **Full Project Name:** Adaptive and Secure Autonomy for UAS: A Modular Approach to Flight Control, Machine Learning Integration, and Multi-Vehicle Coordination
- **Client/Agency:** NASA (Shared Services Center, Stennis Space Center, Mississippi)
- **Contract Type:** SBIR Phase I
- **Contract Number:** 80NSSC25C0155
- **Principal Investigator:** Dr. Jack Elston, Black Swift Technologies LLC
- **Period of Performance:** September 29, 2025 – March 27, 2026 (6 months)
- **Project Status:** **ARCHIVED & COMPLETE** (Final payment received April 16, 2026; project closed)

### Scope Summary
Phase I R&D effort to develop and validate a modular, layered architecture for SwiftCore avionics enabling aircraft autonomy. Key deliverables included:
- Layered architecture definition with pub/sub messaging protocol
- SwiftCore 4.0 firmware updates (SBC and RTOS Autopilot board)
- ML-based automatic PID controller tuning proof-of-concept
- Safe sandbox framework for experimental control modules
- Validation via benchtop simulations, bench tests, and flight tests
- New technology disclosure to NASA via iEdison (March 26, 2026)
