# Project 200-14 — Financial Summary

## Project Overview
- **Full Project Name:** Adaptive and Secure Autonomy for UAS: A Modular Approach to Flight Control, Machine Learning Integration, and Multi-Vehicle Coordination
- **Client/Agency:** NASA (Shared Services Center, Stennis Space Center, MS)
- **Contract Type:** SBIR Phase I
- **Contract Number:** 80NSSC25C0155
- **Period of Performance:** September 29, 2025 – March 27, 2026 (6 months)
- **Principal Investigator:** Dr. Jack Elston
- **Project Status:** **ARCHIVED** — All work completed; project closed April 16, 2026

**Brief Description of Scope:**
Developed a modular, layered architecture for SwiftCore avionics system enabling aircraft autonomy with multi-vehicle coordination and machine learning-based sensing/control. Key deliverables included a 5-layer functional architecture with pub/sub messaging, ML terrain-following module with automated PID tuning, safe sandbox framework for experimental control modules, supervisory controller with safety thresholds, and successful flight/bench testing and integration.
