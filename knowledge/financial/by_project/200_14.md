# Project 200-14 — Financial Summary

## Project Overview
- **Full Project Name:** Adaptive and Secure Autonomy for UAS: A Modular Approach to Flight Control, Machine Learning Integration, and Multi-Vehicle Coordination
- **Client/Agency:** NASA Stennis Space Center, Mississippi
- **Contract Type:** SBIR Phase I
- **Contract Number:** 80NSSC25C0155
- **Period of Performance:** September 29, 2025 – March 27, 2026 (6 months)
- **Project Status:** ARCHIVED & COMPLETE (Final payment received April 16, 2026)
- **Brief Description:** Phase I R&D effort to develop and validate a modular, layered architecture for SwiftCore avionics enabling aircraft autonomy. Work included definition of a five-layer functional architecture with pub/sub messaging protocol, updates to SwiftCore firmware/software (4.0 SBC and RTOS Autopilot board), development of ML-based automatic PID controller tuning, creation of a safe sandbox framework for integrating experimental control modules, and validation via benchtop simulations, bench tests, and flight tests.
