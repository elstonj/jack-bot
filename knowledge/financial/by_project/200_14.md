# Project 200-14 — Financial Summary

## Project Overview
- **Full Project Name:** Adaptive and Secure Autonomy for UAS: A Modular Approach to Flight Control, Machine Learning Integration, and Multi-Vehicle Coordination
- **Client/Agency:** NASA (Stennis Space Center, Mississippi)
- **Contract Type:** SBIR Phase I
- **Contract Number:** 80NSSC25C0155
- **Principal Investigator:** Dr. Jack Elston, Black Swift Technologies LLC
- **Period of Performance:** September 29, 2025 – March 27, 2026 (6 months)
- **Project Status:** **ARCHIVED** — All work completed; final payment received April 16, 2026

**Brief Description of Scope:**  
Development of a modular, layered architecture for the SwiftCore avionics system enabling aircraft autonomy with multi-vehicle coordination and machine learning-based sensing and control. Deliverables included a 5-layer functional architecture with pub/sub messaging protocol, ML-enabled terrain-following flight control, safe sandbox framework, supervisory controller with safety protocols, and comprehensive testing (flight, bench, simulation integration) with JSBSim environment and S2 aircraft parameters.
