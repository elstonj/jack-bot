# Project 200-14 — Financial Summary

## Project Overview
- **Full Project Name:** Adaptive and Secure Autonomy for UAS: A Modular Approach to Flight Control, Machine Learning Integration, and Multi-Vehicle Coordination
- **Client/Agency:** NASA Shared Services Center (Stennis Space Center, MS)
- **Contract Type:** SBIR Phase I
- **Contract Number:** 80NSSC25C0155
- **Period of Performance:** September 29, 2025 – March 27, 2026 (6 months)
- **Principal Investigator:** Dr. Jack Elston, Black Swift Technologies LLC
- **Project Status:** ✅ **ARCHIVED** — All work completed. Final administrative tasks closed April 16, 2026. All deliverables and payments received on schedule with no cost overruns or risks.

**Brief Description of Scope:**  
Develop a modular, layered architecture for the SwiftCore avionics system enabling autonomous aircraft operations with multi-vehicle coordination and ML-based sensing/control. Key deliverables include a 5-layer functional architecture with pub/sub messaging protocol, ML terrain-following module with automated PID tuning, safe sandbox framework, plugin architecture integration, supervisory controller with safety thresholds, and comprehensive flight/bench testing validation.
