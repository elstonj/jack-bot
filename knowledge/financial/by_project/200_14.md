# Project 200-14 — Financial Summary

## Project Overview
- **Full Project Name:** Adaptive and Secure Autonomy for UAS: A Modular Approach to Flight Control, Machine Learning Integration, and Multi-Vehicle Coordination
- **Client/Agency:** NASA (Stennis Space Center, Mississippi)
- **Contract Type:** SBIR Phase I
- **Contract Number:** 80NSSC25C0155
- **Principal Investigator:** Dr. Jack Elston, Black Swift Technologies LLC
- **Period of Performance:** September 29, 2025 – March 27, 2026 (6 months)
- **Project Status:** **ARCHIVED** — All work completed; final payment received and project closed April 16, 2026
- **Brief Description:** Developed a modular, layered architecture for SwiftCore avionics system enabling aircraft autonomy with multi-vehicle coordination and machine learning-based sensing/control. Key deliverables included: 5-layer functional architecture with pub/sub messaging protocol, ML module for terrain-following flight with automated PID control tuning, safe sandbox framework for experimental control modules, plugin architecture integration, and supervisory controller with safety thresholds. All technical work completed April 3, 2026; administrative closure April 16, 2026.
