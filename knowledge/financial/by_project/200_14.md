# Project 200-14 — Financial Summary

## Project Overview
- **Full Project Name:** Adaptive and Secure Autonomy for UAS: A Modular Approach to Flight Control, Machine Learning Integration, and Multi-Vehicle Coordination
- **Client/Agency:** NASA Stennis Space Center, Mississippi
- **Contract Type:** SBIR Phase I
- **Contract Number:** 80NSSC25C0155
- **Principal Investigator:** Dr. Jack Elston, Black Swift Technologies LLC
- **Period of Performance:** September 29, 2025 – March 27, 2026 (6 months)
- **Project Status:** **ARCHIVED** — All work completed successfully; final payment received April 16, 2026

**Scope Description:** Development of a modular, layered architecture for the SwiftCore avionics system enabling autonomous aircraft operations with multi-vehicle coordination, machine learning-based sensing and control, and integrated safety sandbox framework. Technical achievements include a 5-layer functional architecture with pub/sub messaging protocol, ML-enabled terrain-following flight module with automated PID tuning, safe sandbox framework for experimental control modules, plugin architecture integration with SwiftCore firmware, supervisory controller with safety thresholds, and comprehensive flight/bench testing with JSBSim simulation integration.
