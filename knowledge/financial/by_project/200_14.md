# Project 200-14 — Financial Summary

## Project Overview
- **Full Project Name:** Adaptive and Secure Autonomy for UAS: A Modular Approach to Flight Control, Machine Learning Integration, and Multi-Vehicle Coordination
- **Client/Agency:** NASA (Shared Services Center, Stennis Space Center, MS)
- **Contract Type:** SBIR Phase I
- **Contract Number:** 80NSSC25C0155
- **Period of Performance:** September 29, 2025 – March 27, 2026 (6 months)
- **Principal Investigator:** Dr. Jack Elston
- **Project Status:** **ARCHIVED** — All work completed; final payment received April 16, 2026

**Brief Description of Scope:**  
Development of a modular, layered architecture for the SwiftCore avionics system enabling aircraft autonomy with multi-vehicle coordination, machine learning-based sensing/control, safe sandbox framework for experimental modules, and integration of ML terrain-following flight with automated PID control loop tuning. Project included flight and bench testing, JSBSim simulation integration, supervisory controller development, and SwiftCore 4.0 implementation on SBC and RTOS autopilot boards.
