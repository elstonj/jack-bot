# Project 200-14 — Financial Summary

## Project Overview
- **Full Project Name:** Adaptive and Secure Autonomy for UAS: A Modular Approach to Flight Control, Machine Learning Integration, and Multi-Vehicle Coordination
- **Client/Agency:** NASA (Shared Services Center, Stennis Space Center, MS)
- **Principal Investigator:** Dr. Jack Elston
- **Contract Type:** SBIR Phase I
- **Contract Number:** 80NSSC25C0155
- **Period of Performance:** September 29, 2025 – March 27, 2026 (6 months)
- **Project Status:** **ARCHIVED & COMPLETE** (Final payment received April 16, 2026; project closed)

**Brief Description of Scope:**  
Phase I R&D effort to develop and validate a modular, layered architecture for SwiftCore avionics enabling aircraft autonomy. Deliverables included: layered architecture definition, messaging protocol specification, SwiftCore system adaptation (4.0 SBC and RTOS Autopilot board), ML-enabled automatic PID controller tuning, safe sandbox framework for external control modules, and comprehensive flight/bench test validation. Project produced formal technical documentation, interim and final reports, and a Technical and Business Assistance (TABA) report for commercialization strategy.
