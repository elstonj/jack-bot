# Project 200-14 — Financial Summary

## Project Overview
- **Full Project Name:** Adaptive and Secure Autonomy for UAS: A Modular Approach to Flight Control, Machine Learning Integration, and Multi-Vehicle Coordination
- **Client/Agency:** NASA (Shared Services Center, Stennis Space Center, MS)
- **Contract Type:** SBIR Phase I
- **Contract Number:** 80NSSC25C0155
- **Principal Investigator:** Dr. Jack Elston, Black Swift Technologies LLC
- **Period of Performance:** September 29, 2025 – March 27, 2026 (6 months)
- **Project Status:** **ARCHIVED** — All work completed. Final administrative tasks closed April 16, 2026
- **Brief Description of Scope:** Development of modular, layered architecture for SwiftCore avionics system enabling aircraft autonomy with multi-vehicle coordination and machine learning-based sensing and control. Key deliverables include: 5-layer functional architecture with pub/sub messaging protocol; ML terrain-following flight module with automated PID control loop tuning; safe sandbox framework for experimental control modules; plugin architecture integration; supervisory controller with safety thresholds; flight and bench testing; and JSBSim simulation environment integration.
