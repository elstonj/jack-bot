# Project 200-14 — Financial Summary

## Project Overview
- **Full Project Name:** Adaptive and Secure Autonomy for UAS: A Modular Approach to Flight Control, Machine Learning Integration, and Multi-Vehicle Coordination
- **Client/Agency:** NASA / Shared Services Center (Stennis Space Center, MS)
- **Contract Type:** SBIR Phase I
- **Contract Number:** 80NSSC25C0155
- **Principal Investigator:** Dr. Jack Elston, Black Swift Technologies LLC
- **Period of Performance:** September 29, 2025 – March 27, 2026 (6 months)
- **Project Status:** **ARCHIVED** — All work completed and delivered. Final payment received April 16, 2026. Project closure completed with 100% deliverable completion rate (40/40 tasks completed).
- **Brief Description:** Developed a modular, layered architecture for SwiftCore avionics system enabling aircraft autonomy through multi-vehicle coordination and machine learning-based sensing/control. Key deliverables included 5-layer functional architecture with pub/sub messaging protocol, ML module for terrain-following flight with automated PID tuning, safe sandbox framework, plugin architecture, supervisory controller with safety protocols, and comprehensive flight/bench testing validation.
