# Project 200-14 — Financial Summary

## Project Overview
- **Full Project Name:** Adaptive and Secure Autonomy for UAS: A Modular Approach to Flight Control, Machine Learning Integration, and Multi-Vehicle Coordination
- **Client/Agency:** NASA Stennis Space Center, Mississippi (Shared Services Center)
- **Contract Type:** SBIR Phase I
- **Contract Number:** 80NSSC25C0155
- **Principal Investigator:** Dr. Jack Elston, Black Swift Technologies LLC
- **Period of Performance:** September 29, 2025 – March 27, 2026 (6 months)
- **Project Status:** **ARCHIVED** — All work completed successfully; final payment received and project closed April 16, 2026
- **Brief Scope:** Development of a modular, layered architecture for SwiftCore avionics system enabling aircraft autonomy with multi-vehicle coordination, machine learning-based sensing/control, safe sandbox framework for experimental modules, and ML-enabled control loop tuning via automated PID tuning. Technical deliverables included 5-layer functional architecture, pub/sub messaging protocol, terrain-following ML module, supervisory controller with safety thresholds, and successful flight/bench tests.
