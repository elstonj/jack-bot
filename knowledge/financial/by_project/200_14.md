## Project Overview
- **Full Project Name:** Adaptive and Secure Autonomy for UAS: A Modular Approach to Flight Control, Machine Learning Integration, and Multi-Vehicle Coordination
- **Client/Agency:** NASA Shared Services Center (Stennis Space Center, Mississippi)
- **Contract Type:** SBIR Phase I
- **Contract Number:** 80NSSC25C0155
- **Period of Performance:** September 29, 2025 – March 27, 2026 (6 months)
- **Principal Investigator:** Dr. Jack Elston
- **Project Status:** ARCHIVED — All work completed; final administrative tasks closed April 16, 2026

**Brief Description of Scope:**
Development of a modular, layered architecture for the SwiftCore avionics system enabling aircraft autonomy with multi-vehicle coordination, machine learning-based sensing and control, safe sandbox framework for experimental modules, and supervisory controller with safety thresholds. Deliverables included architecture specification, messaging protocol, IT Security Plan, demonstration reports, ML terrain-following module, and final technical report.
