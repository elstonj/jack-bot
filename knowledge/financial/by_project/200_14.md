# Project 200-14 — Financial Summary

## Project Overview
- **Full Project Name:** Adaptive and Secure Autonomy for UAS: A Modular Approach to Flight Control, Machine Learning Integration, and Multi-Vehicle Coordination
- **Project Code:** 200-14
- **Client/Agency:** NASA (Stennis Space Center, Mississippi)
- **Contract Number:** 80NSSC25C0155
- **Contract Type:** Small Business Innovation Research (SBIR) Phase I
- **Principal Investigator:** Dr. Jack Elston
- **Period of Performance:** September 29, 2025 – March 27, 2026 (6 months)
- **Project Status:** **ARCHIVED & COMPLETE** (Final payment received April 16, 2026; project closed)

### Scope Summary
Phase I R&D effort to develop and validate a modular, layered architecture for SwiftCore avionics enabling aircraft autonomy. Work included:
- Layered architecture definition with multi-layer messaging protocol
- SwiftCore 4.0 SBC and RTOS Autopilot board development
- Machine learning–based automatic PID controller tuning proof-of-concept
- Safe sandbox framework for experimental control module integration
- Benchtop simulations, bench tests, and flight test validation
- Technical disclosure to NASA via iEdison (New Technology Summary Report, March 26, 2026)
