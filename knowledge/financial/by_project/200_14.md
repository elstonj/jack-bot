# Project 200-14 — Financial Summary

## Project Overview
- **Project Name:** Autonomy (SwiftCore Modular Architecture for UAS Flight Control and ML Integration)
- **Client/Agency:** NASA Shared Services Center (Stennis Space Center, MS)
- **Contract Type:** SBIR Phase I
- **Contract Number:** 80NSSC25C0155
- **Principal Investigator:** Dr. Jack Elston
- **Period of Performance:** September 29, 2025 – March 27, 2026 (6 months)
- **Project Status:** ✅ **ARCHIVED** — All work completed and final payment received April 16, 2026

**Brief Scope:** Developed modular, layered architecture for SwiftCore avionics system enabling autonomous UAS flight with multi-vehicle coordination, machine learning–based sensing/control, safe sandbox framework for experimental modules, and supervisory controller with safety thresholds. Technical achievements include 5-layer functional architecture with pub/sub messaging protocol, ML terrain-following module with automated PID tuning, JSBSim integration, and successful flight/bench testing.
