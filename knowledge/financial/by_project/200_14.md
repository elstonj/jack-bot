# Project 200-14 — Financial Summary

## Project Overview
- **Project Name:** [200-14] Autonomy
- **Full Title:** Adaptive and Secure Autonomy for UAS: A Modular Approach to Flight Control, Machine Learning Integration, and Multi-Vehicle Coordination
- **Client/Agency:** NASA Stennis Space Center, Mississippi (Shared Services Center)
- **Contract Number:** 80NSSC25C0155
- **Contract Type:** SBIR Phase I (Small Business Innovation Research)
- **Principal Investigator:** Dr. Jack Elston, Black Swift Technologies LLC
- **Period of Performance:** September 29, 2025 – March 27, 2026 (6 months)
- **Project Status:** **ARCHIVED** — All work completed; final administrative tasks closed April 16, 2026

### Brief Scope Description
Development of a modular, layered architecture for SwiftCore avionics system enabling aircraft autonomy through:
- Multi-vehicle coordination and information gathering capabilities
- Machine learning and machine vision-based sensing and control
- Safe sandbox framework for experimental control modules without compromising flight safety
- Supervisory controller with safety thresholds and override protocols
- JSBSim simulation environment integration with terrain-following ML module
- SwiftCore 4.0 implementation on both SBC and RTOS autopilot boards
