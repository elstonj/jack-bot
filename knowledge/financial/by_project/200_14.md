# Project 200-14 — Financial Summary

## Project Overview
- **Full Project Name:** Adaptive and Secure Autonomy for UAS: A Modular Approach to Flight Control, Machine Learning Integration, and Multi-Vehicle Coordination
- **Client/Agency:** NASA (Shared Services Center, Stennis Space Center, Mississippi)
- **Contract Number:** 80NSSC25C0155
- **Contract Type:** SBIR Phase I
- **Principal Investigator:** Dr. Jack Elston, Black Swift Technologies LLC
- **Period of Performance:** September 29, 2025 – March 27, 2026 (6 months)
- **Project Status:** **ARCHIVED & COMPLETE** (Final payment received April 16, 2026; project closed)

**Brief Description of Scope:**
Phase I R&D effort to develop and validate a modular, layered architecture for SwiftCore avionics enabling aircraft autonomy. Work included defining five functional layers (multi-vehicle coordination, ML/machine vision sensing and control, and three additional layers), developing the SwiftCore 4.0 firmware/software for SBC and RTOS autopilot boards, creating an ML-based automatic PID controller tuning proof-of-concept, and establishing a safe sandbox framework for integrating experimental external control modules. All deliverables were validated via benchtop simulations, bench tests, and flight tests.

**Project 200-14 (Autonomy) is financially healthy from a **delivery and payment collection standpoint** (all deliverables completed, all invoices paid on time), but presents a **cost control concern**: actual expenses ($156,500) exceed the Phase I contract award ($150,000) by $6,500.
