## Project Overview
- **Full Project Name:** Adaptive and Secure Autonomy for UAS: A Modular Approach to Flight Control, Machine Learning Integration, and Multi-Vehicle Coordination
- **Client/Agency:** NASA (Shared Services Center, Stennis Space Center, MS)
- **Contract Type:** SBIR Phase I
- **Contract Number:** 80NSSC25C0155
- **Principal Investigator:** Dr. Jack Elston
- **Period of Performance:** September 29, 2025 – March 27, 2026 (6 months)
- **Project Status:** ✅ **ARCHIVED** — All work completed. Final administrative tasks and payment receipt closed April 16, 2026.

**Brief Description of Scope:**
Develop a modular, layered architecture for SwiftCore avionics system enabling aircraft autonomy with multi-vehicle coordination, machine learning-based sensing and control, safe sandbox framework for experimental modules, and supervisory control with safety thresholds. Technical achievements include 5-layer functional architecture with pub/sub messaging, ML terrain-following module with automated PID tuning, JSBSim integration, and successful flight and bench testing.
