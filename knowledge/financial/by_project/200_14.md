# Project 200-14 — Financial Summary

## Project Overview

**Project Name:** Adaptive and Secure Autonomy for UAS: A Modular Approach to Flight Control, Machine Learning Integration, and Multi-Vehicle Coordination

**Client/Agency:** NASA (Stennis Space Center, Mississippi)

**Contract Type:** SBIR Phase I

**Contract Number:** 80NSSC25C0155

**Principal Investigator:** Dr. Jack Elston, Black Swift Technologies LLC

**Period of Performance:** September 29, 2025 – March 27, 2026 (6 months)

**Project Status:** **ARCHIVED** — All work completed; project closed April 16, 2026 (per Asana)

**Brief Description:** Development of a modular, layered architecture for the SwiftCore avionics system enabling autonomous aircraft flight with multi-vehicle coordination, machine learning-based sensing and control, safe sandbox framework for experimental modules, and supervisory flight controller with safety thresholds. Key technical achievements include 5-layer functional architecture, ML terrain-following module with automated PID tuning, plugin architecture integration, and successful flight and bench testing.
