# Project 200-14 — Financial Summary

## Project Overview
- **Full Project Name:** Adaptive and Secure Autonomy for UAS: A Modular Approach to Flight Control, Machine Learning Integration, and Multi-Vehicle Coordination
- **Client/Agency:** NASA (Stennis Space Center, Mississippi)
- **Contract Type:** SBIR Phase I
- **Contract Number:** 80NSSC25C0155
- **Principal Investigator:** Dr. Jack Elston
- **Period of Performance:** September 29, 2025 – March 27, 2026 (6 months)
- **Brief Description of Scope:** Phase I R&D effort to develop and validate a modular, layered architecture for SwiftCore avionics enabling aircraft autonomy. Scope includes: (1) defining and documenting a five-layer architecture with pub/sub messaging protocol; (2) updating SwiftCore firmware/software for SBC and RTOS Autopilot boards; (3) developing ML-based automatic PID controller tuning proof-of-concept; (4) creating a safe sandbox framework for integrating experimental external control modules; and (5) validating via benchtop simulations, bench tests, and flight tests. Project archived and complete as of April 16, 2026.
