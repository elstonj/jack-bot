# Project 200-14 — Financial Summary

## Project Overview
- **Full Project Name:** Adaptive and Secure Autonomy for UAS: A Modular Approach to Flight Control, Machine Learning Integration, and Multi-Vehicle Coordination
- **Client/Agency:** NASA (Shared Services Center, Stennis Space Center, MS)
- **Contract Type:** SBIR Phase I
- **Contract Number:** 80NSSC25C0155
- **Principal Investigator:** Dr. Jack Elston, Black Swift Technologies LLC
- **Period of Performance:** September 29, 2025 – March 27, 2026 (6 months)
- **Project Status:** ✅ **COMPLETED & ARCHIVED** (April 16, 2026)

**Scope Description:** Develop modular, layered architecture for SwiftCore avionics system enabling aircraft autonomy with multi-vehicle coordination, machine learning/machine vision-based sensing and control, safe sandbox framework for experimental modules, and supervisory controller with safety protocols. Technical achievements include 5-layer functional architecture with pub/sub messaging, ML terrain-following module with automated PID tuning, plugin architecture integration, and successful flight/bench testing with JSBSim simulation integration.
