# Project 200-14 — Financial Summary

## Project Overview
- **Full Project Name:** Adaptive and Secure Autonomy for UAS: A Modular Approach to Flight Control, Machine Learning Integration, and Multi-Vehicle Coordination
- **Client/Agency:** NASA (Shared Services Center, Stennis Space Center, MS)
- **Contract Type:** SBIR Phase I
- **Contract Number:** 80NSSC25C0155
- **Period of Performance:** September 29, 2025 – March 27, 2026 (6 months)
- **Project Code:** 200-14
- **Status:** **ARCHIVED** — All work completed; final payment received April 16, 2026
- **Principal Investigator:** Dr. Jack Elston
- **Brief Description:** Developed a modular, layered architecture for SwiftCore avionics system to enable aircraft autonomy through multi-vehicle coordination, machine learning-based sensing/control, safe sandbox framework for experimental modules, and supervisory control with safety thresholds. Project included 5-layer functional architecture with pub/sub messaging, ML terrain-following module with automated PID tuning, flight and bench testing, and comprehensive documentation.
