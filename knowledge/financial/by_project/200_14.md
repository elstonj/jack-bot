# Project 200-14 — Financial Summary

## Project Overview
- **Full Project Name:** Adaptive and Secure Autonomy for UAS: A Modular Approach to Flight Control, Machine Learning Integration, and Multi-Vehicle Coordination
- **Client/Agency:** NASA (Shared Services Center, Stennis Space Center, MS)
- **Contract Type:** SBIR Phase I
- **Contract Number:** 80NSSC25C0155
- **Principal Investigator:** Dr. Jack Elston
- **Period of Performance:** September 29, 2025 – March 27, 2026 (6 months)
- **Project Status:** **ARCHIVED** — All work completed and project closed April 16, 2026

**Brief Description of Scope:**
Developed modular, layered architecture for SwiftCore avionics system enabling aircraft autonomy including multi-vehicle coordination, machine learning-based sensing and control, safe sandbox framework for experimental modules, and supervisory controller with safety thresholds. Deliverables included 5-layer functional architecture with pub/sub messaging protocol, ML terrain-following module with automated PID control loop tuning, SwiftCore 4.0 implementation on SBC and RTOS autopilot boards, JSBSim simulation integration, and flight/bench testing validation.
