# Project 200-14 — Financial Summary

## Project Overview
- **Full Project Name:** Adaptive and Secure Autonomy for UAS: A Modular Approach to Flight Control, Machine Learning Integration, and Multi-Vehicle Coordination
- **Client/Agency:** NASA (Stennis Space Center, Mississippi)
- **Contract Type:** SBIR Phase I
- **Contract Number:** 80NSSC25C0155
- **Period of Performance:** September 29, 2025 – March 27, 2026 (6 months)
- **Principal Investigator:** Dr. Jack Elston, Black Swift Technologies LLC
- **Project Status:** **ARCHIVED** — All work completed and final payment received April 16, 2026

**Brief Description of Scope:**
Developed a modular, layered architecture for the SwiftCore avionics system to enable aircraft autonomy with multi-vehicle coordination, machine learning-based sensing and control, and safe experimental frameworks. Deliverables included a 5-layer functional architecture with pub/sub messaging protocol, ML-enabled terrain-following flight control with automated PID tuning, safe sandbox framework, supervisory controller with safety thresholds, plugin architecture integration, and flight/bench test validation.
