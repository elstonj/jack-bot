# Project 200-14 — Financial Summary

## Project Overview
- **Full Project Name:** Adaptive and Secure Autonomy for UAS: A Modular Approach to Flight Control, Machine Learning Integration, and Multi-Vehicle Coordination
- **Client/Agency:** NASA (Shared Services Center, Stennis Space Center, MS)
- **Contract Type:** SBIR Phase I
- **Contract Number:** 80NSSC25C0155
- **Principal Investigator:** Dr. Jack Elston
- **Period of Performance:** September 29, 2025 – March 27, 2026 (6 months)
- **Project Status:** **ARCHIVED & COMPLETE** (Final payment received April 16, 2026; project closed)

**Brief Description of Scope:**
Phase I R&D effort to develop and validate a modular, layered architecture for SwiftCore avionics enabling aircraft autonomy. Scope includes: defining five-layer functional architecture with pub/sub messaging protocol; updating SwiftCore firmware (4.0 SBC and RTOS Autopilot board); developing ML-based automatic PID controller tuning; creating safe sandbox framework for experimental control modules; and validation via benchtop simulations, bench tests, and flight tests. Four major technical milestones completed with all deliverables closed out as of April 16, 2026.
