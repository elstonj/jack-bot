# Project 200-14 — Financial Summary

## Project Overview
- **Full Project Name:** Adaptive and Secure Autonomy for UAS: A Modular Approach to Flight Control, Machine Learning Integration, and Multi-Vehicle Coordination
- **Client/Agency:** NASA / Shared Services Center (Stennis Space Center, MS)
- **Contract Type:** SBIR Phase I
- **Contract Number:** 80NSSC25C0155
- **Principal Investigator:** Dr. Jack Elston, Black Swift Technologies LLC
- **Period of Performance:** September 29, 2025 – March 27, 2026 (6 months)
- **Project Status:** **ARCHIVED** — All work completed successfully with all deliverables and payments received on schedule (Project archived April 16, 2026)
- **Brief Description of Scope:** Develop modular, layered architecture for SwiftCore avionics system enabling aircraft autonomy with multi-vehicle coordination, machine learning-based sensing and control, safe sandbox framework for experimental modules, and supervisory controller with safety protocols. Work includes flight testing, bench testing, JSBSim simulation integration, and SwiftCore 4.0 development on SBC and RTOS autopilot boards.
