# Project 200-14 — Financial Summary

## Project Overview
- **Full Project Name:** Adaptive and Secure Autonomy for UAS: A Modular Approach to Flight Control, Machine Learning Integration, and Multi-Vehicle Coordination
- **Client/Agency:** NASA (Stennis Space Center, Mississippi)
- **Contract Type:** SBIR Phase I
- **Contract Number:** 80NSSC25C0155
- **Principal Investigator:** Dr. Jack Elston, Black Swift Technologies LLC
- **Period of Performance:** September 29, 2025 – March 27, 2026 (6 months)
- **Project Status:** **ARCHIVED** — All work completed successfully; final administrative closure completed April 16, 2026

**Brief Description of Scope:**  
Development of a modular, layered architecture for the SwiftCore avionics system enabling aircraft autonomy through multi-vehicle coordination, machine learning-based sensing and control, safe sandbox frameworks for experimental modules, and supervisory controllers with safety thresholds. Technical achievements include 5-layer functional architecture with pub/sub messaging, ML terrain-following module with automated PID tuning, JSBSim simulation integration, and successful flight and bench testing.
