# Project 200-14 — Financial Summary

## Project Overview
- **Full Project Name:** Adaptive and Secure Autonomy for UAS: A Modular Approach to Flight Control, Machine Learning Integration, and Multi-Vehicle Coordination
- **Client/Agency:** NASA (Shared Services Center, Stennis Space Center, MS)
- **Contract Type:** SBIR Phase I
- **Contract Number:** 80NSSC25C0155
- **Period of Performance:** September 29, 2025 – March 27, 2026 (6 months)
- **Project Code:** 200-14
- **Status:** **ARCHIVED** — All work completed successfully; final payment received and project closure completed April 16, 2026 (per Asana)
- **Principal Investigator:** Dr. Jack Elston
- **Project Lead/Owner:** Dan Prendergast (Asana); Dr. Jack Elston (Contract PI)

**Brief Description:** Development of a modular, layered architecture for the SwiftCore avionics system enabling autonomous UAS flight operations with multi-vehicle coordination, machine learning-based sensing and control, and safe sandbox framework for experimental control modules. Technical achievements include 5-layer functional architecture with pub/sub messaging, ML terrain-following module with automated PID tuning, supervisory controller with safety protocols, and successful flight/bench testing.
