# Project 200-14 — Financial Summary

## Project Overview
- **Full Project Name:** Adaptive and Secure Autonomy for UAS: A Modular Approach to Flight Control, Machine Learning Integration, and Multi-Vehicle Coordination
- **Client/Agency:** NASA (Shared Services Center, Stennis Space Center, Mississippi)
- **Contract Number:** 80NSSC25C0155
- **Contract Type:** SBIR Phase I
- **Period of Performance:** September 29, 2025 – March 27, 2026 (6 months)
- **Principal Investigator:** Dr. Jack Elston, Black Swift Technologies LLC
- **Project Status:** **ARCHIVED** — All work completed and final payment received as of April 16, 2026

**Brief Scope Description:**
Development of a modular, layered architecture for SwiftCore avionics system enabling aircraft autonomy with multi-vehicle coordination, machine learning-based sensing and control, safe sandbox framework for experimental modules, and supervisory controller with safety protocols. Technical achievements include 5-layer functional architecture, ML-enabled terrain-following flight, plugin architecture integration, and successful flight/bench testing.
