# Project 200-14 — Financial Summary

## Project Overview
- **Full Project Name:** Adaptive and Secure Autonomy for UAS: A Modular Approach to Flight Control, Machine Learning Integration, and Multi-Vehicle Coordination
- **Client/Agency:** NASA (Shared Services Center, Stennis Space Center, MS)
- **Contract Type:** SBIR Phase I
- **Contract Number:** 80NSSC25C0155
- **Principal Investigator:** Dr. Jack Elston, Black Swift Technologies LLC
- **Period of Performance:** September 29, 2025 – March 27, 2026 (6 months)
- **Project Status:** **ARCHIVED & COMPLETE** — All deliverables closed out; final payment received April 16, 2026
- **Brief Description of Scope:** Phase I R&D effort to develop and validate a modular, layered architecture for SwiftCore avionics enabling aircraft autonomy. Work included defining a five-layer functional architecture with pub/sub messaging protocol, adapting SwiftCore firmware (4.0 SBC and RTOS Autopilot board), developing ML-based automatic PID controller tuning, creating a safe sandbox framework for experimental external control modules, and validating via benchtop simulations, bench tests, and flight tests.
