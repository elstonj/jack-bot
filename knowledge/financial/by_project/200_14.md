# Project 200-14 — Financial Summary

## Project Overview
- **Full Project Name:** Adaptive and Secure Autonomy for UAS: A Modular Approach to Flight Control, Machine Learning Integration, and Multi-Vehicle Coordination
- **Client/Agency:** NASA (Shared Services Center, Stennis Space Center, MS)
- **Contract Type:** SBIR Phase I
- **Contract Number:** 80NSSC25C0155
- **Principal Investigator:** Dr. Jack Elston
- **Period of Performance:** September 29, 2025 – March 27, 2026 (6 months)
- **Brief Description of Scope:** Development of a modular, layered architecture for SwiftCore avionics system enabling aircraft autonomy with multi-vehicle coordination, machine learning-based sensing and control, safe sandbox framework for experimental modules, and supervisory controller with safety thresholds. Project included architecture definition, messaging protocol specification, system adaptation, ML-enabled control loop tuning, flight/bench testing, and simulation environment integration (JSBSim).
