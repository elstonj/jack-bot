# Project 200-14 — Financial Summary

## Project Overview
- **Full Project Name:** Adaptive and Secure Autonomy for UAS: A Modular Approach to Flight Control, Machine Learning Integration, and Multi-Vehicle Coordination
- **Project Code:** 200-14 Autonomy
- **Client/Agency:** NASA (Shared Services Center, Stennis Space Center, MS)
- **Contract Number:** 80NSSC25C0155
- **Contract Type:** SBIR Phase I
- **Period of Performance:** September 29, 2025 – March 27, 2026 (6 months)
- **Project Status:** **ARCHIVED & COMPLETE** — Final payment received April 16, 2026; project closed.
- **Technical POC:** Jinu Idicula (NASA, 661-276-2892, jinu.t.idicula@nasa.gov)
- **Billing POC:** James Hibbs (NASA)
- **BST Principal Investigator:** Dr. Jack Elston
- **BST Team:** Dan Prendergast (Owner), Jack Elston, Maciej Stachura, Ben Busby, Meredith O'Hara Needham

**Brief Scope:** Phase I R&D to develop and validate a modular, layered architecture for SwiftCore avionics enabling aircraft autonomy. Deliverables included architecture definition, SwiftCore 4.0 firmware updates (SBC and RTOS Autopilot board), ML-based automatic PID controller tuning, safe sandbox framework for external control modules, and validation via benchtop simulations, bench tests, and flight tests. All four technical milestones completed on schedule; project delivered final report and TABA commercialization assessment to NASA.
