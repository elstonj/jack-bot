# Project 200-14 — Financial Summary

## Project Overview
- **Full Project Name:** Adaptive and Secure Autonomy for UAS: A Modular Approach to Flight Control, Machine Learning Integration, and Multi-Vehicle Coordination
- **Client/Agency:** NASA (Stennis Space Center, Mississippi)
- **Contract Number:** 80NSSC25C0155
- **Contract Type:** SBIR Phase I
- **Principal Investigator:** Dr. Jack Elston, Black Swift Technologies LLC
- **Period of Performance:** September 29, 2025 – March 27, 2026 (6 months)
- **Project Status:** **ARCHIVED** — All work completed; final payment received and project closure completed April 16, 2026

**Project Scope:** Development of a modular, layered architecture for SwiftCore avionics system enabling aircraft autonomy with multi-vehicle coordination, machine learning-based sensing/control, safe sandbox framework for experimental modules, and supervisory controller with safety thresholds. Technical achievements include 5-layer functional architecture with pub/sub messaging, ML terrain-following module with automated PID tuning, plugin architecture integration, and successful flight/bench testing with JSBSim simulation environment.
