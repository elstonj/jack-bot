# Project 200-14 — Financial Summary

## Project Overview
- **Full Project Name:** Adaptive and Secure Autonomy for UAS: A Modular Approach to Flight Control, Machine Learning Integration, and Multi-Vehicle Coordination
- **Client/Agency:** NASA Shared Services Center (Stennis Space Center, MS)
- **Contract Type:** SBIR Phase I
- **Contract Number:** 80NSSC25C0155
- **Principal Investigator:** Dr. Jack Elston
- **Period of Performance:** September 29, 2025 – March 27, 2026 (6 months)
- **Project Status:** **ARCHIVED** — All work completed successfully; project closed April 16, 2026
- **Brief Description:** Development of a modular, layered architecture for SwiftCore avionics system enabling autonomous UAS flight with multi-vehicle coordination, machine learning-based sensing/control, safe sandbox framework for experimental modules, and supervisory control with safety thresholds. Includes integration of ML terrain-following, JSBSim simulation environment, and SwiftCore 4.0 firmware on both SBC and RTOS autopilot boards.
