# Project 200-14 — Financial Summary

## Project Overview
- **Full Project Name:** Adaptive and Secure Autonomy for UAS: A Modular Approach to Flight Control, Machine Learning Integration, and Multi-Vehicle Coordination
- **Client/Agency:** NASA (Shared Services Center, Stennis Space Center, MS)
- **Contract Type:** SBIR Phase I
- **Contract Number:** 80NSSC25C0155
- **Principal Investigator:** Dr. Jack Elston, Black Swift Technologies LLC
- **Period of Performance:** September 29, 2025 – March 27, 2026 (6 months)
- **Project Status:** **ARCHIVED** — All work completed successfully; final administrative tasks closed April 16, 2026

**Brief Scope Description:** Development of a modular, layered architecture for the SwiftCore avionics system enabling aircraft autonomy through: (1) multi-vehicle coordination and information gathering, (2) machine learning and machine vision-based sensing and control. Technical achievements include a 5-layer functional architecture with pub/sub messaging protocol, ML-based terrain-following flight, safe sandbox framework, plugin architecture integration, and supervisory controller with safety thresholds. Successful flight and bench testing, JSBSim simulation integration, and SwiftCore 4.0 development completed on both SBC and RTOS autopilot boards.
