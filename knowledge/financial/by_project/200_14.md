# Project 200-14 — Financial Summary

## Project Overview
- **Project Name:** [200-14] Autonomy
- **Full Title:** Adaptive and Secure Autonomy for UAS: A Modular Approach to Flight Control, Machine Learning Integration, and Multi-Vehicle Coordination
- **Client/Agency:** NASA (Shared Services Center, Stennis Space Center, MS)
- **Contract Type:** SBIR Phase I
- **Contract Number:** 80NSSC25C0155
- **Principal Investigator:** Dr. Jack Elston
- **Period of Performance:** September 29, 2025 – March 27, 2026 (6 months)
- **Project Status:** **ARCHIVED** — All work completed successfully; final administrative tasks and payment received April 16, 2026

**Brief Description of Scope:**  
Development of a modular, layered architecture for SwiftCore avionics system to enable aircraft autonomy with multi-vehicle coordination, machine learning-based sensing and control, safe sandbox framework for experimental modules, and supervisory controller with safety overrides. Deliverables included system architecture definition, messaging protocol specification, SwiftCore system adaptation, safe sandbox development, ML-enabled control loop tuning via hardware-in-the-loop testing, and comprehensive final reporting.
