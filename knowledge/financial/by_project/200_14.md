# Project 200-14 — Financial Summary

## Project Overview
- **Full Project Name:** Adaptive and Secure Autonomy for UAS: A Modular Approach to Flight Control, Machine Learning Integration, and Multi-Vehicle Coordination
- **Client/Agency:** NASA (Stennis Space Center, Mississippi)
- **Contract Type:** SBIR Phase I
- **Contract Number:** 80NSSC25C0155
- **Period of Performance:** September 29, 2025 – March 27, 2026 (6 months)
- **Principal Investigator:** Dr. Jack Elston, Black Swift Technologies LLC
- **Project Status:** **ARCHIVED** — All work completed successfully with all deliverables submitted and final payment received (April 16, 2026)

**Brief Description of Scope:**
Development of a modular, layered architecture for the SwiftCore avionics system enabling aircraft autonomy. Key technical achievements include: five-layer functional architecture with pub/sub messaging protocol; machine learning module for terrain-following flight with automated PID control loop tuning; safe sandbox framework for experimental control modules; plugin architecture integration with SwiftCore firmware/software; and supervisory controller with safety thresholds. Project included successful flight and bench testing, JSBSim simulation integration, and SwiftCore 4.0 development on both SBC and RTOS autopilot boards.
