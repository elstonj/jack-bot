# Project 200-14 — Financial Summary

## Project Overview
- **Full Project Name:** Adaptive and Secure Autonomy for UAS: A Modular Approach to Flight Control, Machine Learning Integration, and Multi-Vehicle Coordination
- **Client/Agency:** NASA / Shared Services Center (Stennis Space Center, MS)
- **Contract Type:** SBIR Phase I
- **Contract Number:** 80NSSC25C0155
- **Principal Investigator:** Dr. Jack Elston, Black Swift Technologies LLC
- **Period of Performance:** September 29, 2025 – March 27, 2026 (6 months)
- **Project Status:** ARCHIVED — All work completed successfully as of April 16, 2026

**Brief Description of Scope:**
Developed a modular, layered architecture for the SwiftCore avionics system enabling aircraft autonomy with multi-vehicle coordination, machine learning-based sensing/control, and safe sandbox frameworks for experimental modules. Deliverables included a 5-layer functional architecture with pub/sub messaging, ML terrain-following module with automated PID tuning, safe sandbox framework, supervisory controller with safety thresholds, JSBSim simulation integration, and SwiftCore 4.0 implementation on both SBC and RTOS autopilot boards. All technical milestones and CLIN deliverables completed on schedule with final payment received April 16, 2026.
