  - Phase II Option I: July 2029 – June 2030 (12 months) — *Proposed*

**Brief Scope Description:**  
Design, build, test, and demonstrate an integrated magnetic field measurement system using small unmanned aircraft systems (UAS). The Phase I Option period (6.5-month compressed timeline) includes ground testing, flight validation, Camp Pendleton field demonstration (Sep 14–25, 2026), and three Navy-mandated administrative reports (CLINs 0005–0007). Technical scope includes on-board magnetic sensor integration (Bartington and QuSpin sensors), Python data analysis tools, and flight-ready magnetometer payload.
