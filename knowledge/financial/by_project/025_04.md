# Project 025-04 — Financial Summary

## Project Overview
**Project Code:** 025-04  
**Project Name:** Next-Generation Methane Monitoring for Orphaned Wells: Leveraging Drone Technology and Continuous Ground-Based Solution  
**Client/Agency:** U.S. Department of Energy (DOE) Fossil Energy and Carbon Management (FECM)  
**Contract Type:** DOE FECM Program (specific solicitation number not provided in available documents)  
**Period of Performance:** Data available from 2025-04 through 2025-09 (proposal submission date: 2025-04-09)  
**Brief Description of Scope:** Integrated methane detection and monitoring system for orphaned well sites combining Black Swift S2 UAS equipped with Quanta3 methane sensor, eddy covariance flux towers, continuous ground monitoring, FluxMapper™ software analysis, and HOO-nah device for remote data transmission. Project aims to advance FluxMapper™ technology from TRL-4/5 to TRL-6 with target 0.2 kg/h methane detection sensitivity.
