# Project 025-04 — Financial Summary

## Project Overview

**Primary Project Identified:** Adaptive and Secure Autonomy for UAS: A Modular Approach to Flight Control, Machine Learning Integration, and Multi-Vehicle Coordination

- **Full Project Name:** Adaptive and Secure Autonomy for UAS: A Modular Approach to Flight Control, Machine Learning Integration, and Multi-Vehicle Coordination
- **Client/Agency:** NASA
- **Contract Type:** Phase I SBIR
- **Program/Solicitation:** NASA SBIR Subtopic A2.02 (Enabling Aircraft Autonomy); ProSAMS Proposal Number A2.02-1017
- **Proposal Date:** 2025-04-08
- **Key Personnel:** Dr. Jack Elston (PI), Dr. Maciej Stachura, Ben Busby
- **Brief Description of Scope:** Development of SwiftCore, a modular and hierarchical avionics platform for UAS that enables hot-swappable components, machine learning integration, and multi-vehicle coordination through an open, message-based communication framework with embedded containers and a "safe sandbox" for secure testing of experimental modules.
