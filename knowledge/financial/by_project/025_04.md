# Project 025-04 — Financial Summary

## Project Overview

**Primary Project (DOE FECM):**
- **Full Project Name:** Next-Generation Methane Monitoring for Orphaned Wells: Leveraging Drone Technology and Continuous Ground-Based Solution
- **Client/Agency:** U.S. Department of Energy (DOE) Fossil Energy and Carbon Management (FECM)
- **Contract Type:** DOE FECM program (specific solicitation number not provided in proposal)
- **Submission Date:** 2025-04-09
- **Brief Description:** Integrated methane detection and monitoring system for orphaned well sites, combining Black Swift S2 UAS with Quanta3 methane sensor, eddy covariance towers, FluxMapper™ software, and HOO-nah remote connectivity device. Project aims to advance FluxMapper™ from TRL-4/5 to TRL-6 with 0.2 kg/h methane detection sensitivity.

**Secondary Proposals in Project Code 025-04 Portfolio:**
- **NASA SBIR Subtopic A2.02** (Enabling Aircraft Autonomy): SwiftCore modular avionics platform for UAS autonomy, machine learning integration, and multi-vehicle coordination (Proposal A2.02-1017; submitted 2025-04-08)
- **Air Force AFWERX SBIR Phase II** (2022.4): Runway Integrity Validation through Soil Moisture Measurements from Small UAS (Contract #400-5; Milestone #7 report dated 2025-04-11)
