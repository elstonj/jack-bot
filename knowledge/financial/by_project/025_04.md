# Project 025-04 — Financial Summary

## Project Overview
**Project Name:** Next-Generation Methane Monitoring for Orphaned Wells: Leveraging Drone Technology and Continuous Ground-Based Solution

**Client/Agency:** U.S. Department of Energy (DOE) Fossil Energy and Carbon Management (FECM)

**Contract Type:** DOE FECM Program (specific solicitation number not provided in proposal)

**Proposal Submission Date:** 2025-04-09

**Period of Performance:** Data not available from proposals. QuickBooks records span 2025-04 through 2025-10.

**Brief Description of Scope:**
Integrated methane detection and monitoring system for orphaned well sites combining Black Swift S2 UAS (equipped with Quanta3 methane sensor) with eddy covariance flux towers, ground-based continuous monitoring, and FluxMapper™ software for data analysis. Project aims to advance FluxMapper™ from TRL-4/5 to TRL-6, achieving 0.2 kg/h methane detection sensitivity with a three-phase development approach including Go/No-Go decision points.

## Key Deliverables & Milestones

**From Proposals (Planned Scope):**

1. **System Integration & Architecture Definition**
   - Define layered architecture (SwiftCore flight management system per NASA SBIR proposal A2.02-1017)
   - Adapt and refine modular UAS control framework

2. **Methane Monitoring System Development**
   - Integrate S2 UAS with Quanta3 methane sensor
   - Deploy eddy covariance flux towers with LI-COR methane evaluation systems
   - Develop FluxMapper™ software integration for multi-source data analysis
   - Integrate HOO-nah device (HPWT) for remote connectivity (per DOE proposal)

3. **Field Testing & Validation**
   - Conduct field trials at orphaned well sites
   - Collect methane flux data across multiple platforms (aerial + ground-based)
   - Validate 0.2 kg/h methane detection sensitivity target
   - Advance FluxMapper™ from TRL-4/5 to TRL-6

4. **Phase Gates & Go/No-Go Decision Points**
   - Three-phase development structure with de-risking checkpoints (per DOE proposal)

5. **Soil Moisture & Runway Integrity Validation** *(separate AFWERX SBIR Phase II project, contract 400-5)*
   - Final field testing at Pond's Field
   - Collection of dry soil moisture data (<10% moisture) to complete cone index algorithm coefficients
   - Development of soil moisture-to-runway integrity mapping
