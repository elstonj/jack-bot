**Contract Type:** DOE FECM Program (specific solicitation number not provided in available documents)

**Proposal Submission Date:** 2025-04-09

**Period of Performance:** Data not available from proposals/budget documents

**Scope Description:** Integrated methane detection and monitoring system for orphaned well sites, combining Black Swift Technologies' S2 UAS equipped with Quanta3 methane sensor, flux tower ground-based monitoring with LI-COR systems, FluxMapper™ software for data integration and analysis, and remote connectivity via HOO-nah device.
