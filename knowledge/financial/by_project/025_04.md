# Project 025-04 — Financial Summary

## Project Overview

**Project Name:** Next-Generation Methane Monitoring for Orphaned Wells: Leveraging Drone Technology and Continuous Ground-Based Solution

**Client/Agency:** U.S. Department of Energy (DOE) Fossil Energy and Carbon Management (FECM)

**Contract Type:** DOE FECM program (specific solicitation number not provided in available documents)

**Period of Performance:** Not explicitly stated in provided documents. QuickBooks data spans 2025-04 through 2025-10 (7 months of activity).

**Brief Description of Scope:** Integrated methane detection and monitoring system for orphaned well sites, combining Black Swift Technologies' S2 UAS equipped with Quanta3 methane sensor, eddy covariance flux towers with LI-COR systems, FluxMapper™ software for data analysis, and HOO-nah device for remote data transmission. Project aims to advance FluxMapper™ technology from TRL-4/5 to TRL-6 with 0.2 kg/h methane detection sensitivity. Three-phase development with Go/No-Go decision points.

**Source:** Proposal dated 2025-04-09 (Proposals & Reports); Actual spend from QuickBooks (unclassified.md)
