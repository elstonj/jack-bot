# Project 025-04 — Financial Summary

## Project Overview
**Project Name:** Next-Generation Methane Monitoring for Orphaned Wells: Leveraging Drone Technology and Continuous Ground-Based Solution

**Client/Agency:** U.S. Department of Energy (DOE) Fossil Energy and Carbon Management (FECM)

**Contract Type:** DOE FECM program (specific solicitation number not provided in available documents)

**Period of Performance:** Proposal submitted 2025-04-09; operational data spans 2025-04 through 2025-10

**Scope Description:** Integrated methane detection and monitoring system for orphaned well sites, combining Black Swift Technologies' S2 UAS platform with flux towers, continuous ground monitoring, and FluxMapper™ software. Project aims to advance FluxMapper™ technology from TRL-4/5 to TRL-6, achieving 0.2 kg/h methane detection sensitivity. Multi-platform approach integrating drone-based aerial detection, ground-based eddy covariance towers with LI-COR methane sensors, data analysis software, and remote connectivity via HOO-nah device (HPWT).
