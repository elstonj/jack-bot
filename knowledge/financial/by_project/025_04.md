**Scope Description:** An integrated methane detection and monitoring system for orphaned well sites combining Black Swift Technologies' S2 UAS equipped with Quanta3 methane sensor, eddy covariance towers with LI-COR methane evaluation systems, FluxMapper™ software for data analysis, and HOO-nah device (HPWT) for remote data transmission.
