# Project 025-04 — Financial Summary

## Project Overview

**Project Code:** 025-04

**Project Name:** Next-Generation Methane Monitoring for Orphaned Wells: Leveraging Drone Technology and Continuous Ground-Based Solution

**Client/Agency:** U.S. Department of Energy (DOE) Fossil Energy and Carbon Management (FECM)

**Contract Type:** DOE FECM Program (type not specified in proposal)

**Proposal Submission Date:** 2025-04-09

**Period of Performance:** Not specified in available documents

**Brief Description of Scope:** 
Integrated methane detection and monitoring system for orphaned well sites combining Black Swift Technologies' S2 UAS equipped with Quanta3 methane sensor, eddy covariance towers with LI-COR methane evaluation systems, FluxMapper™ data analysis software, and HOO-nah device for remote connectivity. Project aims to advance FluxMapper™ technology from TRL-4/5 to TRL-6 with 0.2 kg/h methane detection sensitivity.
