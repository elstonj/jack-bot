# Project 200-11 — Financial Summary

## Project Overview
- **Full Project Name:** Demonstrating Persistent IR Measurements Over Wildfires Using Small, Fixed-Wing Uncrewed Aircraft
- **Client/Agency:** NASA Ames Research Center
- **Contract Type:** SBIR Phase III (Fixed Price)
- **Contract Number:** 80NSSC25CA043
- **Period of Performance:** January 2025 – September 2025 (9 months)
- **Project Status:** ✓ **ARCHIVED / COMPLETED** (Closed November 24, 2025)
- **Brief Scope Description:** Demonstrate persistent infrared (IR) measurements over wildfires using the S2 small fixed-wing uncrewed aircraft platform and establish a scalable operational CONOPS for 24-hour wildfire monitoring. Project included integration of Remote ID detection systems, NightFOX IR payload development, and live demonstration event at Pawnee National Grassland (August 27–28, 2025).
