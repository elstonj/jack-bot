# Project 200-11 — Financial Summary

## Project Overview
- **Full Project Name:** Demonstrating Persistent IR Measurements Over Wildfires Using Small, Fixed-Wing Uncrewed Aircraft
- **Client/Agency:** NASA Ames Research Center
- **Contract Type:** SBIR Phase III (Research & Development)
- **Contract Number:** 80NSSC25CA043
- **Period of Performance:** January 2025 – September 2025 (9 months)
- **Project Status:** ✅ **ARCHIVED & CLOSED** — Contract completed November 24, 2025. All deliverables accepted and all payments received.
- **Brief Scope:** Demonstrate persistent infrared (IR) measurements for wildfire monitoring using the S2 small uncrewed aircraft platform. Key achievements include successful 24-hour persistence demonstration at Pawnee National Grassland (August 27–28, 2025), integration of Remote ID detection systems, and payload data ingestion application development for real-time ADSB packet conversion.
