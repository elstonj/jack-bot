# Project 024-12 — Financial Summary

## Project Overview
**Project Name:** Runway Integrity Validation through Soil Moisture Measurements from a Small UAS (SMM Phase II 22.4D)

**Client/Agency:** Department of Air Force (DAF), Air Force Research Laboratory (AFRL)

**Contract Type:** SBIR Phase II

**Program/Solicitation:** AFWERX SBIR Phase II - Soil Moisture Mapping (2022.4)

**Period of Performance:** Not explicitly provided in source documents. Milestone #5 report dated 2024-12-11 indicates ongoing testing and validation phase.

**Brief Description of Scope:**
This Phase II SBIR project validates runway integrity through soil moisture measurements using a small UAS platform equipped with an L-band radiometer sensor suite. The technical approach includes developing real-time soil moisture calculation capability and onboard/post-processing algorithms to compute soil integrity (cone index) from L-band soil moisture data and soil type classification. Key achievements include resolving RF noise interference issues and completing flight test approval processes for local field testing at Sunny Slope Sod Farm in Longmont, CO.
