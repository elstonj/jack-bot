- **System Components:**
  - Preflight Planning Perk (PF2P): weather and energy forecasting module using NCAR FastEddy™
  - Sensor and Harnessing Control System (SHCS): onboard control for real-time soaring exploitation
  - Integration with SwiftCore FMS, SwiftTab UI, and S0 UAS platform
- **Partners:** BAE Systems (prime), NCAR (FFRDC), UC Santa Barbara (Prof. Hespanha), Woods Hole Oceanographic Institution (Dr. Ventura)
- **Status:** Proposal stage (draft dated 2024-12-18); no formal milestones or deliverable dates provided in documentation

### NASA GPS-Denied Navigation Phase I SBIR
- **Five Technical Work Areas (as proposed):**
  1. Refine and integrate multi-modal sensor suite (altimeters, optical flow, range sensors)
  2. Terrain-relative navigation (TRN) algorithm development
  3. Sensor fusion engine for GPS-denied operation
  4. Machine vision and ICP-based localization
  5. Adaptive weather sensing and autonomous mission planning
- **Key Innovation:** YOLO object detection + modified ICP algorithm for matching detected semantic features to georeferenced navigation database
- **Status:** Phase I proposal submitted 2024-12-11 to 2025-02-25; no award decision or milestone schedule provided
