## Key Deliverables & Milestones
**Source: Proposals & Reports Documents**

From **B2: S0 Measurement Evaluation (Navy STTR Phase I Deliverable)**:
- **Task B.2 – S0 Data Analysis & Error Validation**
  - Validation of S0 meteorological measurements against tower data, dropsondes, radiosondes, and tail Doppler radar
  - Error analysis for wind, turbulence, and height calculations at multiple data frequencies (100 Hz, 50 Hz, 25 Hz, 10 Hz)
  - Deliverable: Technical report on measurement uncertainties and error sources
  - Status: Document last modified 2026-01-02 (recent, likely in progress)

- **Task B.3 – De-icing Strategy Development**
  - Heat MHP (Multi-Hole Pitot Probe) tips using PTC heating
  - Evaluate Ice-X or similar compounds for wings/propellers
  - Potential NASA wind tunnel testing
  - Critical issue: Propeller de-icing identified as "show stopper" requiring resolution
  - Status: Not started or planned for Phase II

- **Task B.5 – Concept of Operations (CONOPS)**
  - S0 Air-Deployed (S0-AD) weather collection system design for Navy deployment
  - Deployment from P-8A Poseidon, C-130, MH-60
  - Mission planning system (SwiftCore) and control tablet (SwiftTab) development
  - Autonomous operation with ditch command capability
  - Status: CONOPS document completed (last modified 2026-01-05); Phase II development planned

**Financial Implications:**
- Significant academic and aerospace subcontractor spend suggests external testing, analysis, and hardware development are underway
- Multiple system variants (S0-AD, S0-VTOL, MHPP) requiring validation and component testing
- Platform integration compatibility testing (P-8, MH-60, C-130) likely requiring specialized facilities and expertise
- De-icing R&D may require additional wind tunnel or field testing resources
