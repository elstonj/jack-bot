## Key Deliverables & Milestones
**Source: Proposals & Reports (B2: S0 Measurement Evaluation, B5: S0 Weather Collection CONOPS)**

The Navy STTR Phase I program includes the following technical deliverables with financial and scheduling implications:

### Task B.2: S0 Measurement Evaluation
- **Data Validation Plan:** Target uncertainties for wind measurements, turbulence estimation, and height calculations
- **Error Analysis:** Testing at multiple data frequencies (100 Hz, 50 Hz, 25 Hz, 10 Hz) to characterize turbulent field leveling
- **Platform Compatibility:** Integration verification with:
  - P-8A Poseidon external pod mounts
  - MH-60 helicopter mounts
  - Sonobuoy launch systems
- **De-icing Strategy Development:**
  - Positive Temperature Coefficient (PTC) heating of Multi-Hole Pitot Probe (MHPP) tips
  - Ice-X or similar de-icing compound evaluation
  - Potential NASA wind tunnel testing (noted as critical path item)
  - Propeller de-icing identified as "show stopper" risk

### Task B.5: S0 Weather Collection CONOPS
- **System Architecture Definition:** S0 Air-Deployed (S0-AD) platform specifications (~3 lbs, <2 ft wingspan)
- **Deployment Sleeve Design:** Adapts folded S0 to launch tube systems with drag parachute
- **Mission Planning Software:** Phase II deliverable (laptop-based system for pre-mission planning and post-mission data download)
- **SwiftTab Control Tablet:** Real-time mission profile adjustment interface
- **Operational Procedures:** Full autonomous operation after deployment from naval aircraft (P-8, C-130, MH-60)

**Schedule Note:** Both deliverables reference Phase I completion dates (document modified 2026-01-02 and 2026-01-05), with Phase II work mentioned as upcoming (mission planning software development deferred).
