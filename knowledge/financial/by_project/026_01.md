- **Program/Solicitation:** Navy STTR, Hazardous Weather Topic
- **Contract Type:** STTR Phase I (with Phase II referenced in proposal materials)
- **Period of Performance:** Data not available from Drive Budget Docs or contracts
- **Brief Description:** Comprehensive evaluation of Black Swift Technologies' S0 uncrewed aircraft system for Navy meteorological data collection. Key technical tasks: measurement validation against tower/dropsonde/radiosonde data, turbulence analysis, heat de-icing system evaluation, and integration planning.
