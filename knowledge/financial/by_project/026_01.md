# Project 026-01 — Financial Summary

## Project Overview
**Project Name:** S0 Measurement Evaluation / S0 Weather Collection Concept of Operations (Navy STTR Phase I)

**Client/Agency:** U.S. Navy

**Contract Type:** Navy STTR Phase I (Hazardous Weather Topic)

**Period of Performance:** Data available from April 2024 through January 2026; Phase I deliverables dated July 2025 – January 2026

**Brief Description:** Task B.2 of a Navy STTR Phase I program focused on validating S0 meteorological measurements, conducting error analysis, developing de-icing strategies, and defining a Concept of Operations (CONOPS) for S0 Air-Deployed (S0-AD) weather collection from naval platforms (P-8, C-130, MH-60). Work includes integration compatibility testing, Multi-Hole Pitot Probe (MHPP) de-icing development, and comprehensive measurement validation against tower data, dropsondes, radiosondes, and radar.
