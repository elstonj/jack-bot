## Key Deliverables & Milestones

**Source: Proposals & Reports (B2: S0 Measurement Evaluation; B5: S0 Weather Collection CONOPS)**

### Phase I Task B.2: S0 Measurement Evaluation
- **Scope:** Error analysis, data validation plan, de-icing strategy development
- **Key Activities:**
  - Integration & platform compatibility evaluation (P-8A Poseidon, MH-60 helicopters, sonobuoy launch systems)
  - Comprehensive error analysis of S0 wind, turbulence, and height measurements
  - Multi-frequency testing (100 Hz, 50 Hz, 25 Hz, 10 Hz) to characterize turbulent fields
  - De-icing strategy: PTC (Positive Temperature Coefficient) heating for Multi-Hole Pitot Probe (MHP); evaluation of Ice-X compounds on wings/propellers
  - Propeller de-icing flagged as critical ("show stopper") issue
- **Deliverable:** Technical Task Plan with detailed validation approach (Document modified 2026-01-02)
- **Financial Implication:** Subcontractor costs for testing (potentially wind tunnel testing via NASA), materials, and de-icing component evaluation

### Phase I Task B.5: S0 Weather Collection Concept of Operations
- **Scope:** CONOPS for S0 Air-Deployed (S0-AD) autonomous weather platform
- **System Components:**
  - S0-AD aircraft (3 lbs, <2 ft wingspan); fully autonomous after deployment
  - Deployment sleeve with drag parachute stabilization
  - SwiftTab control tablet; SwiftCore mission planning computer (to be developed Phase II)
  - VHF datalink and onboard data recorder
- **Deployment Platforms:** P-8 Poseidon, C-130, MH-60
- **Capabilities:** High-resolution atmospheric and ocean-surface data in extreme weather; standoff distance operations
- **Deliverable:** CONOPS document (Document modified 2026-01-05)
- **Financial Implication:** Hardware development, control tablet/mission planning software (deferred to Phase II), prototype integration and testing

### Identified Technical Risks & Cost Drivers
- **Propeller de-icing:** Critical issue requiring resolution; may drive cost overruns if testing/solutions exceed budgeted amount
- **Platform compatibility verification:** Mechanical testing and simulations required
- **Phase II software development:** SwiftCore and SwiftTab control interface development flagged for Phase II (cost implications pending Phase II contract)
