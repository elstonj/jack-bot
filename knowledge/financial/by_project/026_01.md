# Project 026-01 — Financial Summary

## Project Overview
- **Full Project Name:** S0 Measurement Evaluation & Weather Collection (Navy STTR Phase I — Hazardous Weather Topic)
- **Client/Agency:** U.S. Navy
- **Contract Type:** Navy STTR Phase I (transitioning to Phase II)
- **Period of Performance:** Data available from 2024-04-19 through 2026-01-23; Phase I created/modified 2025-07-22 through 2026-01-02
- **Brief Description of Scope:**  
  Comprehensive validation of Black Swift Technologies' S0 uncrewed aircraft system for Navy meteorological data collection. Includes error analysis, integration testing with Navy platforms (P-8A Poseidon, MH-60, C-130), de-icing strategy development for extreme weather operations, and concept of operations (CONOPS) for S0 Air-Deployed (S0-AD) weather collection. Phase I deliverables include Task B.2 measurement evaluation and Task B.5 weather collection CONOPS.
