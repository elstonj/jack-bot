## Key Deliverables & Milestones

**Source: Proposals & Reports (B2: S0 Measurement Evaluation; B5: S0 CONOPS)**

### Phase I Deliverables (On-going):

#### Task B.2: S0 Measurement Evaluation
- **Status:** In progress (document modified 2026-01-02)
- **Key Scope Elements:**
  - Data validation plan with target uncertainties for wind, turbulence, height
  - Error analysis at multiple data frequencies (100 Hz, 50 Hz, 25 Hz, 10 Hz)
  - De-icing strategy development: PTC heating on MHP tips, Ice-X or similar on wings/propellers
  - Propeller de-icing noted as critical ("show stopper") issue
  - Platform compatibility testing: sonobuoy launch systems, P-8A Poseidon external pod mounts, MH-60 helicopter mounts
  - NASA wind tunnel testing (potential, contingent on de-icing strategy)
- **Financial Implications:** Significant testing/evaluation costs; potential additional costs if NASA wind tunnel required

#### Task B.5: S0 Weather Collection CONOPS
- **Status:** In progress (document modified 2026-01-05)
- **Key Scope Elements:**
  - Concept of Operations for S0 Air-Deployed (S0-AD) from Navy platforms
  - System architecture documentation (S0-AD aircraft, deployment sleeve, mission planning computer, SwiftTab tablet, datalink/recorder)
  - Operational procedures for P-8, C-130, MH-60 deployment scenarios
  - Data collection and post-mission download procedures
  - Phase II deliverable: Mission planning computer and SwiftCore system development
- **Financial Implications:** Phase II will include hardware/software development costs for mission planning system
