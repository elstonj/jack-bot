# Project 026-01 — Financial Summary

## Project Overview
- **Full Project Name:** S0 Measurement Evaluation & Weather Collection Development
- **Client/Agency:** United States Navy
- **Contract Type:** Navy STTR Phase I (with Phase II preparation)
- **Program/Solicitation:** Navy STTR, Hazardous Weather Topic
- **Period of Performance:** Not explicitly stated in provided documents; invoices span 2024-04-19 through 2026-01-23
- **Brief Description of Scope:** Development and validation of Black Swift Technologies' S0 uncrewed aircraft system for Navy weather data collection. Work includes measurement error analysis, platform compatibility evaluation (P-8A Poseidon, MH-60 helicopter, sonobuoy launch systems), de-icing strategy development, and operational concept of operations (CONOPS) for S0 Air-Deployed (S0-AD) system. Key technical areas: wind/turbulence measurement validation, Multi-Hole Pitot Probe (MHPP) de-icing, integration testing, and Navy personnel training CONOPS.
