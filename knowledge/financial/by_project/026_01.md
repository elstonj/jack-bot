# Project 026-01 — Financial Summary

## Project Overview
- **Full Project Name:** S0 Measurement Evaluation & Weather Collection (Navy STTR Phase I – Hazardous Weather Topic)
- **Client/Agency:** U.S. Navy
- **Contract Type:** Navy STTR Phase I (transitioning to Phase II)
- **Period of Performance:** Data available 2024–2026; Phase I deliverables completed 2025–2026
- **Brief Description of Scope:** Technical evaluation and validation of Black Swift Technologies' S0 air-deployed uncrewed aircraft system for Navy weather data collection. ## Key Deliverables & Milestones

**Source: Proposals & Reports (Navy STTR Phase I documents)**

### Task B.2: S0 Measurement Evaluation
- **Document Status:** Phase I Deliverable / Technical Task Plan (Created 2025-07-22; last modified 2026-01-02)
- **Key Deliverables:**
  - Error analysis of S0 meteorological data (wind, turbulence, height calculations)
  - Multi-frequency testing plan (100 Hz, 50 Hz, 25 Hz, 10 Hz data rates)
  - De-icing strategy development for MHP (Multi-Hole Pitot Probe) and propellers using PTC heating and Ice-X compounds
  - Platform compatibility verification for Navy launch systems (P-8A Poseidon, MH-60 helicopter mounts)
  - NASA wind tunnel testing (tentative)
  - **Financial Implication:** Propeller de-icing identified as critical "show stopper" issue; scope/cost may expand if external testing (NASA) required.

### Task B.5: S0 Weather Collection CONOPS
- **Document Status:** Concept of Operations (Created 2025-12-16; last modified 2026-01-05)
- **Key Deliverables:**
  - Operational procedures for S0-AD deployment from P-8, C-130, MH-60 platforms
  - Mission planning and data download procedures (SwiftCore system)
  - Real-time control procedures (SwiftTab tablet)
  - Integration specifications for Navy platform compatibility
  - **Delivery Status:** Phase I CONOPS completed; Phase II will develop mission planning computer and data systems
  - **Financial Implication:** Phase II scope includes hardware/software development; budget implications pending Phase II contract award.
