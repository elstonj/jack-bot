# Project 001-00 — Financial Summary

## Project Overview
- **Full Project Name:** Coordinated UAS-Based Plume Tracking
- **Client/Agency:** Defense Threat Reduction Agency (DTRA)
- **Contract Type:** SBIR Phase I Proposal
- **Program/Solicitation:** DTRA252-001 PLUMES; Proposal Number T252-001-0052
- **Submission Date:** May 21, 2025
- **Period of Performance:** 7 months (proposed, Phase I)
- **Brief Description:** AI-integrated, autonomous UAS system to enable real-time detection, tracking, and 3D volumetric reconstruction of airborne plumes using Neural Radiance Fields (NeRFs) and dynamic scene reconstruction. Integration of BST's S2 UAS, SwiftCore™ Flight Management System, and multi-sensor data fusion with subcontractor support from Brookhaven National Laboratory for algorithm development and sensor integration.

## Key Deliverables & Milestones (Phase I Proposed)

From the Technical Volume and Budget Justification:

1. **Laboratory Experiments & Feasibility** (Months 1–4)
   - Controlled testing of NeRF-based plume reconstruction
   - Algorithm validation with synthetic and semi-realistic plume data
   - Sensor suite integration on BST S2 UAS

2. **Field Demonstrations** (Months 4–6)
   - Real-world plume tracking in operationally relevant conditions
   - Multi-view autonomous flight operations
   - Data collection and algorithm performance metrics

3. **Phase I Final Report & Phase II Roadmap** (Month 7)
   - Demonstration results and performance requirements
   - Software infrastructure specification for Phase II prototyping
   - Recommendations for transition to operational platforms

4. **Technical Systems Delivered/Modified**
   - S2 UAS platform with integrated sensor suite (EO/IR cameras, GPS/IMU, environmental sensors)
   - SwiftCore™ Flight Management System enhancements for autonomous plume-following control
   - SwiftTab and SwiftStation ground control integration
   - Physics-informed neural network modules
   - NeRF and Gaussian Splatting algorithm implementations (in partnership with BNL)

**Financial Implications:** Phase I effort is fully-funded at $124,267.75 if awarded. Successful Phase I completion would typically qualify for Phase II follow-on (estimated $600K–$1M+ based on typical SBIR Phase II awards), pending positive technical and financial review.
