# Project 001-00 — Financial Summary

## Project Overview
- **Full Project Name:** Coordinated UAS-Based Plume Tracking (DTRA PLUMES)
- **Client/Agency:** Defense Threat Reduction Agency (DTRA)
- **Contract Type:** SBIR Phase I Proposal
- **Program/Solicitation:** DTRA 252-001 PLUMES; Proposal Number T252-001-0052
- **Period of Performance:** 7 months (proposed; submitted May 21, 2025)
- **Brief Description:** AI-integrated autonomous UAS system for real-time detection, tracking, and 3D volumetric reconstruction of airborne plumes during explosive tests. Core innovation applies Neural Radiance Fields (NeRFs) and neural volumetric reconstruction techniques to reconstruct dynamic, semi-transparent volumes from multi-view imagery. Integration with BST's SwiftCore™ avionics and collaboration with Brookhaven National Laboratory (BNL).
