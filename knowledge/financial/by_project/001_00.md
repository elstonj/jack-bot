# Project 001-00 — Financial Summary

## Project Overview
**Project Name:** Coordinated UAS-Based Plume Tracking (DTRA PLUMES)  
**Client/Agency:** Defense Threat Reduction Agency (DTRA)  
**Contract Type:** SBIR Phase I Proposal  
**Solicitation:** DTRA252-001 PLUMES; Proposal Number T252-001-0052  
**Period of Performance:** 7 months (proposed, 2025)  
**Submission Date:** May 21, 2025  

**Scope:** Development of AI-integrated autonomous UAS system for real-time detection, tracking, and 3D volumetric reconstruction of airborne plumes using Neural Radiance Fields (NeRFs) and dynamic scene reconstruction. Integration with BST's SwiftCore™ Flight Management System, SwiftTab, and SwiftStation. Collaboration with Brookhaven National Laboratory on software development, flight planning, and sensor integration.
