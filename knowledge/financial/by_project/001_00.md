# Project 001-00 — Financial Summary

## Project Overview
- **Full Project Name:** Coordinated UAS-Based Plume Tracking
- **Client/Agency:** Defense Threat Reduction Agency (DTRA)
- **Contract Type:** SBIR Phase I Proposal
- **Program/Solicitation:** DTRA 2025-001 PLUMES; Proposal Number T252-001-0052
- **Period of Performance:** 7 months (Phase I feasibility study)
- **Submission Date:** May 21, 2025
- **Brief Description of Scope:** Development of an AI-integrated, autonomous UAS system to enable real-time detection, tracking, and 3D volumetric reconstruction of airborne plumes using Neural Radiance Fields (NeRFs), neural volumetric reconstruction algorithms, and BST's SwiftCore™ avionics. Phase I will establish technical feasibility through controlled laboratory experiments and field demonstrations. Collaboration with Brookhaven National Laboratory for software development.
