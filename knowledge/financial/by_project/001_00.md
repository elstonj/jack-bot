# Project 001-00 — Financial Summary

## Project Overview
- **Full Project Name:** Coordinated UAS-Based Plume Tracking (DTRA PLUMES)
- **Client/Agency:** Defense Threat Reduction Agency (DTRA)
- **Contract Type:** SBIR Phase I
- **Program/Solicitation:** DTRA 2025-001 PLUMES; Proposal Number T252-001-0052
- **Period of Performance:** 7 months (Phase I)
- **Submission Date:** May 21, 2025
- **Brief Description:** AI-integrated autonomous UAS system for real-time detection, tracking, and 3D volumetric reconstruction of airborne plumes from explosive tests using Neural Radiance Fields (NeRFs), multi-sensor data fusion, and BST's SwiftCore™ Flight Management System. Collaboration with Brookhaven National Laboratory on software development and sensor integration.
