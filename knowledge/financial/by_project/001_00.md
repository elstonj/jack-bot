# Project 001-00 — Financial Summary

## Project Overview
- **Full Project Name:** Coordinated UAS-Based Plume Tracking
- **Client/Agency:** Defense Threat Reduction Agency (DTRA)
- **Contract Type:** SBIR Phase I Proposal
- **Program/Solicitation:** DTRA252-001 PLUMES; Proposal Number T252-001-0052
- **Period of Performance:** 7 months (Phase I)
- **Submission Date:** May 21, 2025
- **Brief Description of Scope:** AI-integrated, autonomous UAS system to enable real-time detection, tracking, and 3D volumetric reconstruction of airborne plumes from explosive tests. System combines Neural Radiance Fields (NeRFs) and dynamic scene reconstruction algorithms with BST's fixed-wing UAS platforms, SwiftCore™ Flight Management System, and vertically-integrated avionics. Phase I establishes technical feasibility through controlled laboratory experiments and field demonstrations. Collaboration includes Brookhaven National Laboratory (BNL) for software development.
