# Project 001-00 — Financial Summary

## Project Overview
- **Full Project Name:** Coordinated UAS-Based Plume Tracking
- **Client/Agency:** Defense Threat Reduction Agency (DTRA)
- **Contract Type:** SBIR Phase I Proposal
- **Solicitation:** DTRA 2025 (DTRA252-001 PLUMES; Proposal T252-001-0052)
- **Submission Date:** May 21, 2025
- **Period of Performance:** 7 months (proposed Phase I effort)
- **Brief Description:** AI-integrated autonomous UAS system for real-time detection, tracking, and 3D volumetric reconstruction of airborne plumes from explosive tests using Neural Radiance Fields (NeRFs) and BST's fixed-wing UAS platforms with SwiftCore™ avionics integration. Phase I establishes technical feasibility through controlled lab experiments and field demonstrations; subcontract collaboration with Brookhaven National Laboratory for software development.
