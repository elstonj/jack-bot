# Project 001-00 — Financial Summary

## Project Overview
- **Full Project Name:** Coordinated UAS-Based Plume Tracking (DTRA PLUMES)
- **Client/Agency:** Defense Threat Reduction Agency (DTRA)
- **Contract Type:** SBIR Phase I Proposal
- **Program/Solicitation:** DTRA 252-001 PLUMES; Proposal Number T252-001-0052
- **Period of Performance:** 7 months (proposed)
- **Proposal Submission Date:** May 21, 2025
- **Brief Description of Scope:** Development of an AI-integrated, autonomous UAS system for real-time detection, tracking, and 3D volumetric reconstruction of airborne plumes during explosive tests. Integration of Neural Radiance Fields (NeRFs), multi-sensor data fusion, and BST's SwiftCore™ Flight Management System with Brookhaven National Laboratory subcontract for software development.

## Technical Scope & Key Deliverables

**Source:** Technical Volume (Proposal, submitted 2025-05-21)

### Phase I Objectives:
1. **Neural Volumetric Reconstruction Algorithms** – Integration of NeRF, K-Planes, HexPlane, Dex-NeRF for dynamic plume reconstruction
2. **Multi-Sensor Data Fusion Platform** – EO/IR cameras, GPS/IMU, environmental sensors
3. **SwiftCore™ Integration** – Closed-loop autonomous flight control based on plume reconstruction
4. **Physics-Informed Neural Networks (PINNs)** – Algorithm enhancement
5. **Real-Time Reconstruction Techniques** – Gaussian Splatting, NeRFPlayer
6. **Controlled Lab Experiments & Field Demonstrations** – Performance validation
7. **Phase II Requirements & Software Infrastructure** – Transition planning

### Proposed BST Products/Systems Involved:
- **S2 UAS** (primary platform)
- **SwiftCore™ Flight Management System** (autonomous control integration)
- **SwiftTab** (mission planning)
- **SwiftStation** (ground control)

### Subcontractor Role (Brookhaven NL):
- Software development for neural volumetric capture
- Algorithm implementation and validation
- Integration testing with BST platforms
