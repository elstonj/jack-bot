# Project 001-00 — Financial Summary

## Project Overview
- **Full Project Name:** Coordinated UAS-Based Plume Tracking (DTRA PLUMES)
- **Client/Agency:** Defense Threat Reduction Agency (DTRA)
- **Contract Type:** SBIR Phase I Proposal
- **Program/Solicitation:** DTRA 2025-252-001 PLUMES; Proposal Number T252-001-0052
- **Period of Performance:** 7 months (proposed)
- **Proposal Submission Date:** May 21, 2025
- **Brief Description:** AI-integrated autonomous UAS system for real-time detection, tracking, and 3D volumetric reconstruction of airborne plumes using Neural Radiance Fields (NeRFs) and dynamic scene reconstruction. Integrates BST's S2 UAS, SwiftCore™ Flight Management System, and multi-sensor platforms. Phase I establishes technical feasibility through controlled laboratory experiments and field demonstrations in collaboration with Brookhaven National Laboratory.
