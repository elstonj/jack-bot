# Project 001-00 — Financial Summary

## Project Overview
- **Full Project Name:** Coordinated UAS-Based Plume Tracking
- **Client/Agency:** Defense Threat Reduction Agency (DTRA)
- **Contract Type:** SBIR Phase I Proposal
- **Solicitation:** DTRA252-001 PLUMES; Proposal Number T252-001-0052
- **Period of Performance:** 7 months (proposal submitted May 21, 2025)
- **Brief Description:** AI-integrated autonomous UAS system for real-time detection, tracking, and 3D volumetric reconstruction of airborne plumes using Neural Radiance Fields (NeRFs). Includes multi-sensor data fusion, SwiftCore™ avionics integration, and physics-informed neural networks. Phase I establishes technical feasibility through controlled laboratory experiments and field demonstrations in collaboration with Brookhaven National Laboratory.

## Key Deliverables & Milestones

**Source:** Coordinated UAS-Based Plume Tracking Technical Volume (Proposal)

Phase I deliverables include:

1. **Controlled Laboratory Experiments** — Testing neural volumetric reconstruction algorithms on synthetic and semi-realistic plume imagery
2. **Field Demonstrations** — Real-world plume tracking using BST UAS platforms (S2 UAS with SwiftCore™ Flight Management System)
3. **Performance Requirements Document** — Specification of system performance metrics and constraints for Phase II
4. **Software Infrastructure** — Modular algorithms for NeRF-based plume reconstruction, physics-informed neural networks (PINNs), Gaussian Splatting, and NeRFPlayer techniques
5. **Integration with SwiftCore™ Avionics** — Closed-loop autonomous flight control based on plume reconstruction
6. **Final Report** — Phase I findings and Phase II prototype requirements
