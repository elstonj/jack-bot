# Project 001-00 — Financial Summary

## Project Overview
- **Full Project Name:** Coordinated UAS-Based Plume Tracking (DTRA PLUMES)
- **Client/Agency:** Defense Threat Reduction Agency (DTRA)
- **Contract Type:** SBIR Phase I Proposal
- **Program/Solicitation:** DTRA 2025-2-001 PLUMES; Proposal Number T252-001-0052
- **Period of Performance:** 7 months (proposed)
- **Submission Date:** May 21, 2025
- **Brief Description:** AI-integrated, autonomous UAS system for real-time detection, tracking, and 3D volumetric reconstruction of airborne plumes during explosive tests. Core innovation applies Neural Radiance Fields (NeRFs) and neural volumetric reconstruction techniques to plume characterization. Integrates BST's S2 UAS platform, SwiftCore™ Flight Management System, and multi-sensor data fusion with closed-loop autonomous flight control. Phase I establishes technical feasibility through controlled laboratory experiments and field demonstrations.
