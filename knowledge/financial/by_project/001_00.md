# Project 001-00 — Financial Summary

## Project Overview

**Project Name:** Coordinated UAS-Based Plume Tracking (DTRA PLUMES)  
**Client/Agency:** Defense Threat Reduction Agency (DTRA)  
**Contract Type:** SBIR Phase I Proposal  
**Solicitation:** DTRA 2025 (DTRA252-001 PLUMES; Proposal #T252-001-0052)  
**Proposal Submission Date:** May 21, 2025  
**Period of Performance:** 7 months (proposed)  

**Brief Description of Scope:**  
Development of an AI-integrated, autonomous UAS system to enable real-time detection, tracking, and 3D volumetric reconstruction of airborne plumes produced during explosive tests. The project combines Neural Radiance Fields (NeRFs) and dynamic scene reconstruction algorithms with BST's fixed-wing UAS platforms and SwiftCore™ Flight Management System avionics. Phase I establishes technical feasibility through controlled laboratory experiments and field demonstrations. Key partner: Brookhaven National Laboratory (BNL) for software development and algorithm implementation.

3. **Risk Areas (if awarded)**

   - **Personnel Availability:** Heavy reliance on PI (Dr. Jack Elston) and System Engineer (Dr. Maciej Stachura). Any staffing changes could impact execution

   - **Risk:** If Phase I extends beyond 7 months, budget overrun is likely
