# Project 001-00 — Financial Summary

## Project Overview
- **Full Project Name:** Coordinated UAS-Based Plume Tracking (DTRA PLUMES)
- **Client/Agency:** Defense Threat Reduction Agency (DTRA)
- **Contract Type:** SBIR Phase I Proposal
- **Program/Solicitation:** DTRA 2025-001 PLUMES; Proposal Number T252-001-0052
- **Period of Performance:** 7 months (proposal submitted May 21, 2025)
- **Brief Description of Scope:** Development of AI-integrated autonomous UAS system for real-time detection, tracking, and 3D volumetric reconstruction of airborne plumes during explosive tests. Core innovation combines Neural Radiance Fields (NeRFs) and dynamic scene reconstruction algorithms with BST's S2 UAS platforms and SwiftCore™ Flight Management System. Phase I establishes technical feasibility through controlled laboratory experiments and field demonstrations in collaboration with Brookhaven National Laboratory.

## Technical Scope & Deliverables (From Proposal)

### Key Technical Elements
1. Neural volumetric reconstruction using NeRF-based algorithms and extensions (K-Planes, HexPlane, Dex-NeRF)
2. Multi-sensor data fusion platform integrating EO/IR cameras, GPS/IMU telemetry, environmental sensors
3. Integration with BST's SwiftCore™ avionics for closed-loop autonomous flight control
4. Physics-informed neural networks (PINNs) for enhanced accuracy
5. Gaussian Splatting and NeRFPlayer techniques for near-real-time reconstruction
6. Modular, open-architecture software infrastructure

### Systems & Products Referenced
- **S2 UAS** (primary airborne platform)
- **SwiftCore™ Flight Management System** (avionics integration)
- **SwiftTab** (ground control interface)
- **SwiftStation** (processing/data management)

### Phase I Objectives
- Establish technical feasibility through controlled laboratory experiments and field demonstrations
- Develop performance requirements for Phase II
- Create software infrastructure and algorithm validation framework
