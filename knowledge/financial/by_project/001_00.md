# Project 001-00 — Financial Summary

## Project Overview
**Project Name:** Coordinated UAS-Based Plume Tracking  
**Client/Agency:** Defense Threat Reduction Agency (DTRA)  
**Contract Type:** SBIR Phase I Proposal  
**Program/Solicitation:** DTRA252-001 PLUMES; Proposal Number T252-001-0052  
**Submission Date:** May 21, 2025  
**Period of Performance:** 7 months (proposed)  

**Scope Description:**  
BST proposes an AI-integrated, autonomous UAS system to enable real-time detection, tracking, and 3D volumetric reconstruction of airborne plumes produced during explosive tests. The system combines Neural Radiance Fields (NeRFs) and dynamic scene reconstruction algorithms with BST's S2 UAS platforms and SwiftCore™ Flight Management System. Phase I will establish technical feasibility through controlled laboratory experiments and field demonstrations, with software development and sensor integration conducted in collaboration with Brookhaven National Laboratory (BNL).

## Key Deliverables & Milestones

*From Technical Volume and Budget Justification:*

**Phase I Objectives (7-month effort):**
1. **Laboratory Experiments** — Controlled validation of NeRF-based plume reconstruction techniques
2. **Field Demonstrations** — Real-world testing of coordinated drone-based plume tracking system
3. **Performance Requirements Document** — Specifications for Phase II prototyping
4. **Software Infrastructure** — Flight planning implementation and sensor integration on BST UAS platforms
5. **Final Report** — Technical findings, performance data, and Phase II recommendations

**Core Technical Deliverables:**
- Integration of Neural Radiance Fields (NeRFs) and related volumetric reconstruction algorithms with BST platforms
- Multi-sensor data fusion platform (EO/IR cameras, GPS/IMU telemetry, environmental sensors)
- SwiftCore™ avionics integration for closed-loop autonomous flight control
- Physics-informed neural networks (PINNs) for enhanced accuracy
- Real-time or near-real-time reconstruction capability (Gaussian Splatting, NeRFPlayer techniques)
