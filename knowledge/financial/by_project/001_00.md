# Project 001-00 — Financial Summary

## Project Overview
- **Full Project Name:** Coordinated UAS-Based Plume Tracking
- **Client/Agency:** Defense Threat Reduction Agency (DTRA)
- **Contract Type:** SBIR Phase I Proposal
- **Program/Solicitation:** DTRA 2025-001 PLUMES; Proposal Number T252-001-0052
- **Proposal Submission Date:** May 21, 2025
- **Period of Performance:** 7 months (proposed)
- **Brief Description:** AI-integrated autonomous UAS system for real-time detection, tracking, and 3D volumetric reconstruction of airborne plumes during explosive tests. Integration of Neural Radiance Fields (NeRFs) with BST's S2 UAS platform and SwiftCore™ Flight Management System. Collaboration with Brookhaven National Laboratory.

## Key Deliverables & Milestones

**Data Source:** Technical Volume and Budget Justification documents

### Phase I Deliverables (7-month timeline)

1. **Technical Feasibility Establishment**
   - Controlled laboratory experiments with NeRF-based plume reconstruction algorithms
   - Field demonstrations with BST UAS platform

2. **Technical Output**
   - Performance requirements specification for Phase II
   - Software infrastructure design documentation
   - Integration requirements for SwiftCore™ avionics with autonomous plume tracking

3. **Key Technical Components** (per proposal)
   - Neural volumetric reconstruction (NeRF algorithms, K-Planes, HexPlane, Dex-NeRF)
   - Multi-sensor data fusion platform (EO/IR cameras, GPS/IMU, environmental sensors)
   - Physics-informed neural networks (PINNs)
   - Gaussian Splatting and NeRFPlayer near-real-time reconstruction
   - Modular, open integration with BST platforms

4. **Systems Involved**
   - S2 UAS platform
   - SwiftCore™ Flight Management System
   - SwiftTab, SwiftStation (ground control)
   - Sensor integration on BST avionics
