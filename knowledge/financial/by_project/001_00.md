## Project Overview
- **Full Project Name:** Coordinated UAS-Based Plume Tracking
- **Client/Agency:** Defense Threat Reduction Agency (DTRA)
- **Contract Type:** SBIR Phase I Proposal
- **Program/Solicitation:** DTRA 2025-2 PLUMES; Proposal Number T252-001-0052

## Technical Scope & BST Systems

*Source: Technical Volume and Budget Justification*

**BST Products/Systems Proposed:**
- S2 UAS (primary platform)
- SwiftCore™ Flight Management System (avionics & autonomous flight control)
- SwiftTab (operator interface)
- SwiftStation (ground station)
- Multi-sensor payload integration (EO/IR cameras, GPS/IMU, environmental sensors)

**Key Technical Deliverables (Phase I):**
- Neural volumetric reconstruction algorithms using NeRF-based techniques (K-Planes, HexPlane, Dex-NeRF)
- Multi-view imagery fusion from airborne platforms
- Physics-informed neural network (PINN) enhancements
- Gaussian Splatting and NeRFPlayer implementation for near-real-time reconstruction
- Integration of plume reconstruction with SwiftCore™ for closed-loop autonomous flight
- Performance requirements and software infrastructure documentation for Phase II
