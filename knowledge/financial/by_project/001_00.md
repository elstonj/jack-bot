# Project 001-00 — Financial Summary

## Project Overview
- **Full Project Name:** Coordinated UAS-Based Plume Tracking
- **Client/Agency:** Defense Threat Reduction Agency (DTRA)
- **Contract Type:** SBIR Phase I Proposal
- **Program/Solicitation:** DTRA 252-001 PLUMES; Proposal Number T252-001-0052
- **Period of Performance:** 7 months (proposal submitted May 21, 2025)
- **Brief Description:** AI-integrated autonomous UAS system to enable real-time detection, tracking, and 3D volumetric reconstruction of airborne plumes using Neural Radiance Fields (NeRFs) and dynamic scene reconstruction. Integration with BST's SwiftCore™ Flight Management System and collaboration with Brookhaven National Laboratory for advanced plume characterization.
