# Project 001-00 — Financial Summary

## Project Overview
- **Full Project Name:** Coordinated UAS-Based Plume Tracking
- **Client/Agency:** Defense Threat Reduction Agency (DTRA)
- **Program/Solicitation:** DTRA 2025, DTRA252-001 PLUMES
- **Proposal Number:** T252-001-0052
- **Contract Type:** SBIR Phase I Proposal
- **Period of Performance:** 7 months (proposed in May 2025)
- **Brief Description:** Development of AI-integrated, autonomous UAS system to enable real-time detection, tracking, and 3D volumetric reconstruction of airborne plumes during explosive tests. System combines Neural Radiance Fields (NeRFs) with BST's S2 UAS platform, SwiftCore™ Flight Management System, and vertically-integrated avionics. Phase I establishes technical feasibility through controlled laboratory experiments and field demonstrations.

## Technical Scope Summary
**Source: SBIR Phase I Technical Volume**

**Core Technologies:**
- Neural Radiance Fields (NeRFs) and extensions (K-Planes, HexPlane, Dex-NeRF)
- Gaussian Splatting and NeRFPlayer for near-real-time reconstruction
- Physics-Informed Neural Networks (PINNs)
- Multi-sensor data fusion (EO/IR cameras, GPS/IMU, environmental sensors)
- Integration with BST SwiftCore™ avionics for closed-loop autonomous flight control

**BST Systems Leveraged:**
- S2 UAS (primary platform)
- SwiftCore™ Flight Management System
- SwiftTab (mission planning/display)
- SwiftStation (ground station)

**Subcontractor Support:**
- Brookhaven National Laboratory: Algorithm development, software integration, data processing
