# Project 001-00 — Financial Summary

## Project Overview
- **Full Project Name:** Coordinated UAS-Based Plume Tracking (DTRA PLUMES)
- **Client/Agency:** Defense Threat Reduction Agency (DTRA)
- **Contract Type:** SBIR Phase I Proposal
- **Program/Solicitation:** DTRA252-001 PLUMES; Proposal Number T252-001-0052
- **Period of Performance:** 7 months (proposed, 2025–2025)
- **Brief Description:** Development of AI-integrated autonomous UAS system combining Neural Radiance Fields (NeRFs) and dynamic scene reconstruction algorithms with Black Swift Technologies' fixed-wing UAS platforms and SwiftCore™ Flight Management System to enable real-time detection, tracking, and 3D volumetric reconstruction of airborne plumes during explosive tests. Includes multi-sensor data fusion, closed-loop autonomous flight control, physics-informed neural networks, and modular software architecture.
