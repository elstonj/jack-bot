# Project 001-00 — Financial Summary

## Project Overview

**Project Name:** Coordinated UAS-Based Plume Tracking (DTRA PLUMES)

**Client/Agency:** Defense Threat Reduction Agency (DTRA)

**Contract Type:** SBIR Phase I Proposal

**Solicitation:** DTRA252-001 PLUMES; Proposal Number T252-001-0052

**Period of Performance:** 7 months (Phase I); proposal submitted May 21, 2025

**Brief Description of Scope:**
Black Swift Technologies proposes development of an AI-integrated, autonomous UAS system for real-time detection, tracking, and 3D volumetric reconstruction of airborne plumes from explosive tests. The system integrates Neural Radiance Fields (NeRFs) and dynamic scene reconstruction algorithms with BST's fixed-wing UAS platforms and SwiftCore™ avionics. Phase I establishes technical feasibility through controlled laboratory experiments and field demonstrations; Phase II will prototype the full system. Key partner: Brookhaven National Laboratory (BNL).
