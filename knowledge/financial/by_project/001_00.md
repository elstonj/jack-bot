# Project 001-00 — Financial Summary

## Project Overview
- **Full Project Name:** Coordinated UAS-Based Plume Tracking (DTRA PLUMES)
- **Client/Agency:** Defense Threat Reduction Agency (DTRA)
- **Contract Type:** SBIR Phase I Proposal
- **Solicitation:** DTRA 2025, Proposal Number T252-001-0052
- **Period of Performance:** 7 months (proposed)
- **Submission Date:** May 21, 2025

**Scope Description:** Development of an AI-integrated, autonomous UAS system for real-time detection, tracking, and 3D volumetric reconstruction of airborne plumes during explosive tests. The system integrates Neural Radiance Fields (NeRFs) with BST's fixed-wing UAS platforms (S2 UAS), SwiftCore™ Flight Management System, and vertically-integrated avionics. Phase I will establish technical feasibility through controlled laboratory experiments and field demonstrations, with performance requirements and software infrastructure to be delivered for Phase II prototyping. Collaboration with Brookhaven National Laboratory (BNL) for algorithm development and neural volumetric capture technology.

## Key Deliverables & Milestones

*Source: DTRA PLUMES Technical Volume Proposal*

The proposal outlines a Phase I effort with the following anticipated deliverables (specific dates not provided in proposal excerpt):

### Phase I Deliverables:
- **Technical Feasibility Assessment** – Proof of concept for NeRF-based plume reconstruction using airborne multi-view imagery
- **Controlled Laboratory Experiments** – Validation of neural volumetric reconstruction algorithms in controlled conditions
- **Field Demonstrations** – Real-world testing with BST UAS platforms under operationally relevant conditions
- **Performance Requirements Document** – Definition of system performance specifications for Phase II
- **Software Infrastructure** – Foundational software architecture for Phase II prototyping, including:
  - Integration of NeRF algorithms (K-Planes, HexPlane, Dex-NeRF) with SwiftCore™ Flight Management System
  - Multi-sensor data fusion framework (EO/IR cameras, GPS/IMU, environmental sensors)
  - Physics-informed neural networks (PINNs) for enhanced accuracy
  - Real-time reconstruction capability via Gaussian Splatting and NeRFPlayer techniques

### Brookhaven National Laboratory Collaboration:
- Software development for neural volumetric capture algorithms (primary technical contribution)
- Lead: Dr. Gijs de Boer
- Effort: ~1.5 months allocated across 3 researchers

**Financial Implications:** Subcontract cost of $66,000.00 (53% of proposed budget) allocated to BNL. Delivery of Phase II-ready software and performance specifications will determine contract value and Phase II award eligibility.
