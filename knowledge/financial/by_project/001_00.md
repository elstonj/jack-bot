# Project 001-00 — Financial Summary

## Project Overview
- **Full Project Name:** Coordinated UAS-Based Plume Tracking
- **Client/Agency:** Defense Threat Reduction Agency (DTRA)
- **Contract Type:** SBIR Phase I Proposal
- **Program/Solicitation:** DTRA 2025 (DTRA252-001 PLUMES; Proposal Number T252-001-0052)
- **Period of Performance:** 7 months (proposed, 2025)
- **Submission Date:** May 21, 2025
- **Brief Description of Scope:** Development of an AI-integrated, autonomous UAS system for real-time detection, tracking, and 3D volumetric reconstruction of airborne plumes using Neural Radiance Fields (NeRFs) and dynamic scene reconstruction. Includes multi-sensor data fusion, SwiftCore™ avionics integration, physics-informed neural networks, and collaboration with Brookhaven National Laboratory for software development and sensor integration on BST's UAS platforms.
