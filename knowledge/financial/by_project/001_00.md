# Project 001-00 — Financial Summary

## Project Overview
- **Full Project Name:** Coordinated UAS-Based Plume Tracking (DTRA PLUMES)
- **Client/Agency:** Defense Threat Reduction Agency (DTRA)
- **Contract Type:** SBIR Phase I
- **Program/Solicitation:** DTRA252-001 PLUMES; Proposal Number T252-001-0052
- **Period of Performance:** 7 months (proposal date: May 21, 2025)
- **Brief Description:** AI-integrated autonomous UAS system for real-time detection, tracking, and 3D volumetric reconstruction of airborne plumes using Neural Radiance Fields (NeRFs) and neural volumetric reconstruction algorithms. Integration with BST's SwiftCore™ Flight Management System and fixed-wing UAS platforms. Collaboration with Brookhaven National Laboratory on software development and sensor integration.

## Key Deliverables & Milestones

**Source:** Technical Volume proposal (DTRA Proposal T252-001-0052)

**Phase I Scope (7 months):**
1. **Technical Feasibility Establishment**
   - Controlled laboratory experiments validating NeRF-based plume reconstruction
   - Algorithm development and refinement
   
2. **Field Demonstrations**
   - Deployment of autonomous UAS with integrated neural volumetric reconstruction
   - Real-time plume tracking and 3D reconstruction demonstration
   
3. **Final Deliverables**
   - Performance requirements documentation
   - Software infrastructure and architecture for Phase II prototyping
   - Technical reports and demonstration results
   
4. **Key Technical Milestones**
   - Integration of Neural Radiance Fields (NeRFs) and extensions (K-Planes, HexPlane, Dex-NeRF) into flight system
   - Multi-sensor data fusion (EO/IR cameras, GPS/IMU, environmental sensors)
   - Closed-loop autonomous flight control based on plume reconstruction via SwiftCore™
   - Physics-informed neural networks (PINNs) implementation
   - Gaussian Splatting and NeRFPlayer near-real-time reconstruction

**Milestone Financial Implications:** No specific milestone payments or progress-based funding gates are documented in the proposals provided. Standard Phase I funding is a fixed amount ($124,267.75 proposed).
