# Project 001-00 — Financial Summary

## Project Overview
- **Full Project Name:** Coordinated UAS-Based Plume Tracking (DTRA PLUMES)
- **Client/Agency:** Defense Threat Reduction Agency (DTRA)
- **Contract Type:** SBIR Phase I Proposal
- **Program/Solicitation:** DTRA252-001 PLUMES; Proposal Number T252-001-0052
- **Period of Performance:** 7 months (proposed; submitted May 21, 2025)
- **Brief Description of Scope:** Development of AI-integrated autonomous UAS system for real-time detection, tracking, and 3D volumetric reconstruction of airborne plumes during explosive tests. Integrates Neural Radiance Fields (NeRFs) with BST's fixed-wing UAS platforms and SwiftCore™ Flight Management System. Phase I focuses on technical feasibility via laboratory experiments and field demonstrations.
