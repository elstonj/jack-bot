# Project 001-00 — Financial Summary

## Project Overview
- **Full Project Name:** Coordinated UAS-Based Plume Tracking
- **Client/Agency:** Defense Threat Reduction Agency (DTRA)
- **Contract Type:** SBIR Phase I Proposal
- **Program/Solicitation:** DTRA252-001 PLUMES; Proposal Number T252-001-0052
- **Submission Date:** May 21, 2025
- **Period of Performance:** 7 months (proposed)
- **Brief Description of Scope:** Development of an AI-integrated, autonomous UAS system for real-time detection, tracking, and 3D volumetric reconstruction of airborne plumes using Neural Radiance Fields (NeRFs) and dynamic scene reconstruction algorithms. Project combines BST's S2 UAS platforms with SwiftCore™ Flight Management System and includes collaboration with Brookhaven National Laboratory.
