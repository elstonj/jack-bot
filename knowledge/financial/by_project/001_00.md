# Project 001-00 — Financial Summary

## Project Overview
- **Full Project Name:** Coordinated UAS-Based Plume Tracking (DTRA PLUMES)
- **Client/Agency:** Defense Threat Reduction Agency (DTRA)
- **Contract Type:** SBIR Phase I Proposal
- **Program/Solicitation:** DTRA252-001 PLUMES; Proposal Number T252-001-0052
- **Period of Performance:** 7 months (proposal submitted May 21, 2025)
- **Brief Description of Scope:** Development of AI-integrated, autonomous UAS system for real-time detection, tracking, and 3D volumetric reconstruction of airborne plumes using Neural Radiance Fields (NeRFs) and BST's SwiftCore™ Flight Management System. Phase I will establish technical feasibility through controlled laboratory experiments and field demonstrations.

## Key Deliverables & Milestones

From Proposal Technical Volume:

1. **Phase I Objectives (7-month effort):**
   - Establish technical feasibility of NeRF-based plume reconstruction on UAS platforms
   - Conduct controlled laboratory experiments validating neural volumetric reconstruction
   - Perform field demonstrations with real or simulated plume scenarios
   - Develop performance requirements document for Phase II

2. **Phase I Deliverables (proposed):**
   - Technical feasibility report with algorithm performance metrics
   - Software prototypes for NeRF-based volumetric reconstruction
   - Flight planning and autonomous control integration with SwiftCore™
   - Phase II performance requirements and cost estimate
   - Demonstration videos and field test reports

3. **Key Technical Milestones:**
   - Laboratory validation of NeRF algorithms on semi-transparent plume scenes
   - Sensor integration and multi-view data collection (EO/IR cameras, IMU/GPS)
   - Closed-loop flight control integration with autonomous plume tracking
   - Real-time or near-real-time reconstruction demonstration (Gaussian Splatting/NeRFPlayer)

4. **Phase II (if awarded):**
   - Full prototyping and integration
   - Operationally relevant field demonstrations
   - Transition to government-ready deployment
