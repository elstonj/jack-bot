# Project 001-00 — Financial Summary

## Project Overview
- **Full Project Name:** Coordinated UAS-Based Plume Tracking
- **Client/Agency:** Defense Threat Reduction Agency (DTRA)
- **Contract Type:** SBIR Phase I Proposal
- **Program/Solicitation:** DTRA 2025-001 PLUMES; Proposal Number T252-001-0052
- **Period of Performance:** 7 months (Proposal submitted May 21, 2025)
- **Brief Description of Scope:** Development of an AI-integrated, autonomous UAS system to enable real-time detection, tracking, and 3D volumetric reconstruction of airborne plumes using Neural Radiance Fields (NeRFs). The system integrates BST's S2 UAS platform, SwiftCore™ Flight Management System, and avionics with Brookhaven National Laboratory (BNL) software development capabilities for plume characterization in operationally relevant conditions.

## Key Deliverables & Milestones

**Source:** Technical Volume proposal (Coordinated UAS-Based Plume Tracking); Budget Justification

**Phase I (7 months):**
1. **Controlled Laboratory Experiments** – Validate NeRF-based plume reconstruction algorithms in controlled environment
2. **Field Demonstrations** – Demonstrate autonomous plume tracking in operationally relevant conditions
3. **Performance Requirements Document** – Define technical requirements and success criteria for Phase II
4. **Software Infrastructure** – Develop modular, open-source software stack for Phase II prototyping
5. **Final Report** – Comprehensive Phase I findings and recommendations

**Key Technical Deliverables:**
- Neural volumetric reconstruction pipeline (NeRF, K-Planes, HexPlane, Dex-NeRF, Gaussian Splatting, NeRFPlayer)
- Multi-sensor data fusion integration (EO/IR cameras, GPS/IMU, environmental sensors)
- SwiftCore™ avionics integration for closed-loop autonomous flight control
- Physics-informed neural networks (PINNs) implementation
- Demonstration of real-time or near-real-time plume reconstruction
