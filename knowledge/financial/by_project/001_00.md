# Project 001-00 — Financial Summary

## Project Overview
- **Full Project Name:** Coordinated UAS-Based Plume Tracking (DTRA PLUMES)
- **Client/Agency:** Defense Threat Reduction Agency (DTRA)
- **Contract Type:** SBIR Phase I Proposal
- **Solicitation:** DTRA 2025 (DTRA252-001 PLUMES; Proposal Number T252-001-0052)
- **Period of Performance:** 7 months (proposed, 2025)
- **Submission Date:** May 21, 2025
- **Brief Description of Scope:** Development of an AI-integrated, autonomous UAS system for real-time detection, tracking, and 3D volumetric reconstruction of airborne plumes using Neural Radiance Fields (NeRFs), multi-sensor data fusion, and integration with BST's SwiftCore™ avionics and S2 UAS platforms. Phase I will establish technical feasibility through controlled laboratory experiments and field demonstrations. Key subcontractor: Brookhaven National Laboratory.

## Key Deliverables & Milestones
(From Proposal Documents)

**Proposed Phase I Deliverables (7-month effort):**
1. **Laboratory Testing & Validation** — Controlled experiments with plume generation to validate NeRF-based reconstruction algorithms and sensor fusion
2. **Field Demonstrations** — Flight demonstrations showcasing autonomous plume tracking and real-time 3D volumetric reconstruction
3. **Performance Requirements Document** — Specification of system performance metrics, accuracy, latency, and operational constraints for Phase II
4. **Software Infrastructure** — Development of flight planning algorithms, sensor integration modules, and closed-loop autonomous control integration with SwiftCore™
5. **Final Technical Report** — Summary of Phase I findings, technical feasibility assessment, and Phase II roadmap

**Systems/Products Integrated:**
- BST S2 UAS platform
- SwiftCore™ Flight Management System
- SwiftTab
- SwiftStation
- Multi-sensor suite (EO/IR cameras, GPS/IMU, environmental sensors)

**Key Subcontractor Deliverables (Brookhaven NL):**
- Software development for neural volumetric reconstruction algorithms
- Integration support for plume tracking workflow

**Financial Implications:** Phase I proposed budget is fixed at $124,267.75. Phase II transition contingent on Phase I technical success and Government funding decision.
