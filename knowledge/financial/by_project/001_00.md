# Project 001-00 — Financial Summary

## Project Overview
- **Full Project Name:** Coordinated UAS-Based Plume Tracking
- **Client/Agency:** Defense Threat Reduction Agency (DTRA)
- **Contract Type:** SBIR Phase I
- **Program/Solicitation:** DTRA252-001 PLUMES; Proposal Number T252-001-0052
- **Period of Performance:** 7 months (proposed); Proposal submitted May 21, 2025
- **Brief Description:** Development of an AI-integrated, autonomous UAS system to enable real-time detection, tracking, and 3D volumetric reconstruction of airborne plumes from explosive tests. The system combines Neural Radiance Fields (NeRFs) with BST's S2 UAS platform, SwiftCore™ Flight Management System, and avionics. Phase I establishes technical feasibility through controlled lab experiments and field demonstrations. Collaboration with Brookhaven National Laboratory for software development and algorithm generation.
