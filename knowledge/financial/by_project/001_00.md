# Project 001-00 — Financial Summary

## Project Overview
- **Full Project Name:** Coordinated UAS-Based Plume Tracking (DTRA PLUMES)
- **Client/Agency:** Defense Threat Reduction Agency (DTRA)
- **Contract Type:** SBIR Phase I Proposal
- **Solicitation:** DTRA252-001 PLUMES; Proposal Number T252-001-0052
- **Proposal Submission Date:** May 21, 2025
- **Period of Performance:** 7 months (proposed)
- **Brief Description of Scope:** Development of an AI-integrated, autonomous UAS system to enable real-time detection, tracking, and 3D volumetric reconstruction of airborne plumes using Neural Radiance Fields (NeRFs) and dynamic scene reconstruction algorithms. System integrates BST's S2 UAS platform with SwiftCore™ Flight Management System and multi-sensor data fusion capabilities. Phase I will establish technical feasibility through controlled laboratory experiments and field demonstrations.
