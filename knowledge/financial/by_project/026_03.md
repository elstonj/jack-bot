# Project 026-03 — Financial Summary

## Project Overview
- **Full Project Name:** [200-14] Autonomy
- **Client/Agency:** NASA
- **Contract Type:** Government R&D / Phase I SBIR-equivalent effort
- **Period of Performance:** 2026-03-27 to 2026-04-16 (project completed ahead of original schedule)
- **Brief Description of Scope:** Development and validation of a modular, layered architecture for SwiftCore avionics enabling autonomous aircraft operations. Work includes architecture definition, firmware/software updates (SwiftCore 4.0 SBC and RTOS Autopilot board), machine learning–based PID controller tuning, safe sandbox development for external control modules, and comprehensive validation via benchtop simulations, bench tests, and flight tests. Five functional layers defined: multi-vehicle coordination, ML-based sensing/control, and three additional layers. Final deliverables include technical documentation, reports, and NASA iEdison technology disclosure.
