**Scope Description:**  
Phase I R&D effort to develop and validate a modular, layered architecture for SwiftCore avionics enabling aircraft autonomy. Work included defining a five-layer functional architecture with pub/sub messaging protocol, updating SwiftCore firmware (4.0 SBC and RTOS Autopilot board), developing ML-based automatic PID controller tuning, creating a safe sandbox framework for integrating experimental control modules, and validating designs via benchtop simulations, bench tests, and flight tests.
