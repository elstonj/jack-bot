# Project 025-11 — Financial Summary

## Project Overview
**Project Code:** 025-11

**Full Project Name:** Navy SBIR Magnetometer Phase 1 Project (Sonobuoy-Launched UAV for ASW)

**Client/Agency:** U.S. Navy

**Contract Type:** Navy SBIR N251-016 "Expendable Sonobuoy-Launched Unmanned Aerial Vehicle for ASW Cued Search, Detection, Tracking, and Classification"

**Period of Performance:** Data not available from proposals/contract docs

**Brief Description of Scope:**  
Development of a sonobuoy-launched unmanned aerial vehicle for anti-submarine warfare (ASW) operations. Phase 1 focuses on magnetometer integration testing on the S0 UAS platform, including electromagnetic interference isolation work, shielding optimization, and concurrent hydrophone/acoustic sensor development. Testing includes motor/battery EMI characterization, MuMetal shielding optimization, and sensor placement validation.
