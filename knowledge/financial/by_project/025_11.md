## Key Deliverables & Milestones

**Source: Proposals & Reports (Meeting notes and SOW)**

### Navy SBIR Magnetometer Integration (N251-016)
- **Status (as of 2025-11-12):** Phase 1 ongoing; electromagnetic compatibility (EMC) testing underway
- **Key Activities:**
  - Isolation testing (motor and batteries separately using test rig)
  - MuMetal shielding modular testing
  - Hydrophone/acoustic sensor concurrent development
  - Filter analysis (10 Hz and unfiltered frequency domain characterization)
- **Technical Milestones:** EMC validation, sensor placement optimization (magnetometer in nose or ≤1 ft forward), motor/battery EMI characterization
- **Financial Implication:** Phase 1 budget and contract value not provided in available docs

### ByLight Mustang G2 Fixed-Wing UAS (BYL-LRFE SOW)
- **Period of Performance:** 9 weeks (start date inferred from SOW creation: 2025-11-25)
- **Effort 1:** SwiftCore integration into Mustang Unit 3 for baseline data collection (rapid)
- **Effort 2:** Full G2 design, COTS procurement, assembly, comprehensive flight testing with SwiftCore autopilot
- **Performance Requirements:**
  - ≤55 lbs gross takeoff weight
  - 400–450 km range
  - Truck/government launcher compatibility
  - DoD autopilot enablement (EchoMAV/Cube systems handoff to ByLight)
- **Deliverables:** Flight-test data, system identification data (NetCDF export), G2 airframe and avionics integration
- **Financial Implication:** Three invoices received to date (1714, 1715, 1716 totaling $300,000 from 2025-10-09 to 2025-11-24) mapped to [043-2] By Light Mustang; additional costs for 1706, 1697 ([043-1] By Light Prototype Build: $5,100.15 total)
