# Project 025-11 — Financial Summary

## Project Overview
**Project Code:** 025-11  
**Project Name:** Navy SBIR Magnetometer Phase 1 Project  
**Client/Agency:** U.S. Navy  
**Contract Type:** Navy SBIR N251-016 "Expendable Sonobuoy-Launched Unmanned Aerial Vehicle for ASW Cued Search, Detection, Tracking, and Classification"  
**Period of Performance:** Data available from 2024-04-19 to 2025-11-24  
**Brief Description of Scope:**  
Black Swift Technologies is developing a sonobuoy-launched unmanned aerial vehicle for anti-submarine warfare (ASW) operations under Navy SBIR Phase 1 funding. The project focuses on magnetometer integration testing on the S0 UAS platform, including electromagnetic interference isolation work, shielding optimization, and concurrent hydrophone/acoustic sensor development. Technical approach includes EMC testing, modular MuMetal shielding trials, and frequency domain analysis to optimize sensor placement and performance.

**Source:** Proposals & Reports (Navy SBIR Magnetometer Phase 1 Project, 2025-11-12)
