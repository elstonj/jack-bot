# Project 025-11 — Financial Summary

## Project Overview

**Project Code:** 025-11

**Full Project Name:** Navy SBIR Phase 1 — Expendable Sonobuoy-Launched Unmanned Aerial Vehicle for ASW Cued Search, Detection, Tracking, and Classification

**Client/Agency:** U.S. Navy

**Contract Type:** Navy SBIR N251-016

**Period of Performance:** Data not available from proposals/reports; QuickBooks invoices span 2024-04-19 through 2025-11-24.

**Brief Description of Scope:** Development of a sonobuoy-launched unmanned aerial vehicle (UAS) platform for anti-submarine warfare (ASW) operations. Phase 1 focus includes magnetometer integration testing on the S0 UAS platform, electromagnetic interference (EMI) isolation work, shielding optimization, and concurrent hydrophone/acoustic sensor development. BST is conducting phased electromagnetic compatibility (EMC) testing including isolation testing, MuMetal shielding evaluation, and frequency domain analysis to optimize sensor placement and reduce motor/battery EMI.
