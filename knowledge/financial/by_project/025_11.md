# Project 025-11 — Financial Summary

## Project Overview

**Project Code:** 025-11  
**Project Name:** Navy SBIR Magnetometer Phase 1 Project  
**Client/Agency:** U.S. Navy  
**Program/Solicitation:** Navy SBIR N251-016 "Expendable Sonobuoy-Launched Unmanned Aerial Vehicle for ASW Cued Search, Detection, Tracking, and Classification"  
**Contract Type:** SBIR Phase 1  
**Period of Performance:** Data not available from proposals/budget docs  
**Brief Description:** Development of a sonobuoy-launched unmanned aerial vehicle (UAS) for anti-submarine warfare (ASW) operations. Primary technical focus includes magnetometer integration testing on the S0 UAS platform, electromagnetic interference (EMI) isolation, shielding optimization, and concurrent hydrophone/acoustic sensor development. The project leverages Black Swift's S0 UAS platform and SwiftCore autopilot technology.
