# Project 025-11 — Financial Summary

## Project Overview
**Project Code:** 025-11  
**Project Name:** Navy SBIR Magnetometer Phase 1 (Sonobuoy-Launched UAS for ASW)  
**Client/Agency:** U.S. Navy  
**Program/Solicitation:** Navy SBIR N251-016 "Expendable Sonobuoy-Launched Unmanned Aerial Vehicle for ASW Cued Search, Detection, Tracking, and Classification"  
**Contract Type:** SBIR Phase 1  
**Period of Performance:** Data available through November 2025 (Phase 1 ongoing)  
**Brief Description of Scope:**  
Development of a sonobuoy-launched unmanned aerial vehicle (UAS) for anti-submarine warfare (ASW) operations. Technical work includes magnetometer integration testing on the S0 UAS platform, electromagnetic interference (EMI) isolation and shielding optimization, and concurrent hydrophone/acoustic sensor development. As of November 12, 2025, the project is in active testing phase with EMC validation underway.
