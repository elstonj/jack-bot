# Project 025-11 — Financial Summary

## Project Overview
**Project Code:** 025-11

**Project Name:** Navy SBIR Magnetometer Phase 1 – Sonobuoy-Launched UAS for ASW Operations

**Client/Agency:** U.S. Navy

**Contract Type:** SBIR Phase 1

**Program/Solicitation:** Navy SBIR N251-016 "Expendable Sonobuoy-Launched Unmanned Aerial Vehicle for ASW Cued Search, Detection, Tracking, and Classification"

**Period of Performance:** Data not available from proposals/reports

**Brief Description of Scope:** Development and testing of magnetometer integration on the S0 UAS platform for anti-submarine warfare (ASW) applications, including electromagnetic compatibility (EMC) testing, shielding optimization, and concurrent hydrophone/acoustic sensor development. Project leverages Black Swift's S0 UAS and SwiftCore autopilot platform.
