# Project 025-11 — Financial Summary

## Project Overview
**Project Code:** 025-11  
**Full Project Name:** Black Swift S0 Platform / Multi-Program Portfolio  
**Client/Agency:** Multiple (NOAA Aircraft Operations Center / Department of Commerce; ByLight / Mustang UAS Program; U.S. Navy SBIR)  
**Contract Types:** IDIQ (Indefinite Delivery/Indefinite Quantity); SBIR Phase I; Commercial SOW  
**Period of Performance:** 2024–2025 (invoicing activity from April 2024 through November 2025)  
**Brief Description of Scope:**  
Project 025-11 represents a portfolio of work across multiple customers and platforms centered on Black Swift's S0 UAS platform and SwiftCore flight computer. Work includes:
- **NOAA/DOC 2026 IDIQ**: Platform procurement, training delivery, operational support, course development, documentation, modeling/integration, and testing services for the Black Swift S0 platform.
- **ByLight Mustang Program (BYL-LRFE)**: 9-week, two-effort program for long-range fixed-wing UAS development (Mustang G2) with SwiftCore integration and DoD autopilot enablement.
- **Navy SBIR Phase I (N251-016)**: Magnetometer integration and sonobuoy-launched UAS development for anti-submarine warfare using the S0 platform.
