# Project 025-11 — Financial Summary

## Project Overview
**Project Code:** 025-11  
**Primary Program:** Navy SBIR N251-016 "Expendable Sonobuoy-Launched Unmanned Aerial Vehicle for ASW Cued Search, Detection, Tracking, and Classification"  
**Client/Agency:** U.S. Navy  
**Contract Type:** Navy SBIR Phase I  
**Period of Performance:** Data available from 2024-04-19 through 2025-11-24  
**Brief Description:** Development and testing of a sonobuoy-launched unmanned aerial vehicle (UAS) equipped with magnetometer and hydrophone/acoustic sensors for anti-submarine warfare (ASW) operations. Primary platform: S0 UAS with SwiftCore autopilot. Phase 1 activities focus on electromagnetic compatibility (EMC) testing, magnetometer integration, shielding optimization, and sensor validation.

**Note:** Project 025-11 appears to consolidate multiple related BST activities. QuickBooks data references several project codes ([043-2] By Light Mustang, [301-3] S0 Hurricane Phase II, [018-1] Murphy's Pond CH4, etc.), indicating a portfolio structure. This summary synthesizes available financial data across these code categories as they relate to the Navy SBIR magnetometer/ASW vehicle development.
