## Key Deliverables & Milestones

**Data Source:** Proposals/Reports (Navy SBIR Status Meeting, 2025-11-12)

The Navy SBIR Phase 1 project focuses on magnetometer integration testing. Key technical milestones and deliverables include:

1. **Electromagnetic Compatibility (EMC) Testing**
   - Isolation testing of motor and battery EMI using dedicated test rig
   - MuMetal shielding material sourcing and optimization
   - Placement validation (target: nose-mounted or ≤1 foot forward of aircraft)
   - Status (as of 2025-11-12): Ongoing; clean 30-minute baseline test completed at "Sod Farm" location

2. **Sensor Integration**
   - Magnetometer integration on S0 UAS platform
   - Concurrent hydrophone/acoustic sensor development
   - Status: Testing phase; filter validation underway (10 Hz filtering applied; unfiltered characterization in progress)

3. **Data Validation & Reporting**
   - Frequency domain analysis to optimize shielding placement
   - Characterization of motor vs. battery EMI signatures
   - Status: Data collection ongoing; uncertainty remains on interference source attribution
