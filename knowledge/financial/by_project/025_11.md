## Key Deliverables & Milestones

**Source: Proposals & Reports Documents**

### Navy SBIR Magnetometer Phase 1 (Meeting dated 2025-11-12)
- **Magnetometer Integration Testing**: Ongoing electromagnetic compatibility (EMC) testing on S0 UAS platform
  - Isolation testing of motor and batteries with dedicated test rig
  - MuMetal shielding strategy and placement optimization
  - Target: Position magnetometer ≤1 foot from aircraft nose
  - Status: Testing underway; clean 30-minute validation test completed at "Sod Farm" location
  - Hydrophone/acoustic sensor development concurrent

- **Technical Milestones**: Motor EMI characterization, filter optimization, placement validation
- **Financial Implications**: Ongoing engineering effort; no specific milestone billing mentioned in available documents

  - Course development (FFP, milestone-based)
  - Testing (T&M, Not-To-Exceed per campaign)

- **Status**: Framework document prepared; no active deployments or milestones dated in provided materials

### ByLight Mustang G2 Program (SOW dated 2025-11-25, modified 2025-12-05)
- **Duration**: 9-week, two-effort program
- **Effort 1**: SwiftCore integration into Mustang Unit 3 for baseline data collection
- **Effort 2**: Full G2 design, COTS procurement, assembly, comprehensive flight testing with SwiftCore as primary flight computer
- **Deliverables**: 
  - Fully electric fixed-wing UAS (Mustang G2) meeting DoD requirements
  - ≤55 lbs gross takeoff weight, 400–450 km range
  - Truck/government launcher compatibility
  - Handoff to ByLight for government-provided autopilot integration
- **Recent Invoices** (ByLight Mustang [043-2] and [043-1]):
