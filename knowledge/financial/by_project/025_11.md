# Project 025-11 — Financial Summary

## Project Overview
**Project Code:** 025-11  
**Project Name:** Navy SBIR Magnetometer Phase 1 (Sonobuoy-Launched UAS for ASW)  
**Client/Agency:** U.S. Navy  
**Program/Solicitation:** Navy SBIR N251-016 "Expendable Sonobuoy-Launched Unmanned Aerial Vehicle for ASW Cued Search, Detection, Tracking, and Classification"  
**Contract Type:** SBIR Phase I  
**Period of Performance:** Data available through November 2025 (Phase 1 ongoing)  
**Brief Description:** Black Swift Technologies is developing magnetometer integration and electromagnetic compatibility (EMC) testing for the S0 UAS platform to enable sonobuoy-launched autonomous deployment for anti-submarine warfare operations. Work includes motor/battery EMI isolation testing, MuMetal shielding optimization, magnetometer nose placement, and concurrent hydrophone/acoustic sensor development.
