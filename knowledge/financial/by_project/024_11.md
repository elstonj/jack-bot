# Project 024-11 — Financial Summary

## Project Overview

**Project Identification:** Project code 024-11  
**Client/Agency:** Multiple (primary projects identified: DOE FECM Methane Leak Detection, NOAA Testbed / National Hurricane Center)  
**Contract Type:** Mixed (Federal R&D programs: SBIR Phase II, NOAA Testbed)  
**Period of Performance:** Data available November 2024 – September 2025 (partial year); multi-year scope indicated in NOAA Testbed proposal (3-year program)  
**Brief Description of Scope:**

Project 024-11 aggregates multiple concurrent Black Swift Technologies initiatives:
- **DOE FECM Methane Leak Detection:** Deployment of S2 fixed-wing UAS equipped with Quanta3 methane spectrometer for automated detection and quantification of methane emissions from orphaned oil and gas wells; technology at TRL 5, targeting cost reduction from $750 to <$100 per well.
- **NOAA Testbed / National Hurricane Center Integration:** Three-year program to integrate S0 uncrewed aircraft wind data into NHC forecasting operations, including reduction factor development, validation, and operational implementation via Embry-Riddle Aeronautical University as prime contractor with BST as service provider.
