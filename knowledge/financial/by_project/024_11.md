## Key Deliverables & Milestones

**Data not available from Asana.** No Asana task list, milestones, or deliverable schedule provided for Project 024-11.

**From Proposals/Reports — Expected Deliverables:**

### NOAA Testbed Program (via Embry-Riddle SOW)
- **Year 1 (Reduction Factor Development):** Derive standardization factor to convert S0 wind measurements to 10-meter/1-minute reference standard using 2024 flight data and dropsonde/radar validation
- **Year 2 (Validation & Testbed Operations):** Run historical storm hindcasts with/without reduction factor; demonstrate forecast improvement to NHC
- **Year 3 (Operational Implementation):** Implement reduction factor in ground station processing; integrate into HDOBS real-time data stream for NHC delivery

### DOE FECM Methane Leak Detection Program
- **Technical Validation:** Field validation of S2 UAS with Quanta3 methane spectrometer using flux tower comparison testing
- **Cost Demonstration:** Validate $100/well detection cost vs. current $750/well ground approach
- **System Readiness:** Advance technology from TRL 5 (demonstrated) toward field-ready state
