# Project 039-1 — Financial Summary

## Project Overview
- **Full Project Name**: Refurbished S2 Oklahoma State
- **Client/Agency**: Oklahoma State University (Board of Regents for Oklahoma State University and the A&M Colleges); OK Aerospace Institute (OAIRE)
- **Primary Contact**: Jamey Jacob, OK Aerospace Institute, Tulsa, OK (jdjacob@okstate.edu, 405-744-3208)
- **Contract Type**: Purchase Order (Educational/Research Equipment Procurement)
- **Period of Performance**: December 11, 2024 – August 19, 2025
- **Brief Description**: Complete overhaul and refurbishment of S2 UAS flight system with pneumatic launcher and multi-hole probe. - **Project Status**: **ARCHIVED/COMPLETED** — All work delivered March 14, 2025; operator training completed August 19, 2025. Project closed successfully with minor 11-day delivery delay (March 14 vs. March 3) due to customer spring weather observation timeline requirements.
