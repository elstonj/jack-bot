# Project 039-1 — Financial Summary

## Project Overview
- **Full Project Name:** Refurbished S2 Oklahoma State
- **Client/Agency:** Oklahoma State University, Board of Regents for Oklahoma State University and the A&M Colleges
- **Contract Type:** Purchase Order (Equipment/Systems Sale)
- **Period of Performance:** December 11, 2024 (PO received) – October 21, 2025 (Project archived)
- **Primary Contact:** Jamey Jacob, OK Aerospace Institute (jdjacob@okstate.edu, 405-744-3208)
- **Buyer Contact:** Teresa Blakley (teresa.blakley@okstate.edu, 405-744-8584)

**Brief Scope Description:**  
Refurbished S2 UAS flight system with pneumatic launcher and multi-hole probe. Work included comprehensive aircraft system overhaul (motor replacement, avionics upgrades including ADS-B, Remote ID, RTK integration, battery cycling and replacement, launcher system overhaul, component replacements), delivery via specialized freight logistics, and operator training at OSU. Project completed successfully with all deliverables delivered and training completed by August 19, 2025. Archived October 21, 2025.
