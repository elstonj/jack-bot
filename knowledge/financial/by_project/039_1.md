# Project 039-1 — Financial Summary

## Project Overview
- **Full Project Name:** Refurbished S2 Oklahoma State
- **Client/Agency:** Oklahoma State University (Board of Regents for Oklahoma State University and the A&M Colleges); Contact: Jamey Jacob, OK Aerospace Institute
- **Contract Type:** Purchase Order (Equipment/Systems procurement)
- **Contract/PO Number:** P1454424 (issued December 11, 2024)
- **Period of Performance:** December 11, 2024 – August 19, 2025
- **Project Scope:** Refurbished S2 UAS flight system (SwiftCore™ FMS, SwiftTab™ control tablet, Futaba handset, RTK ground control unit, toolkit), S2 Pneumatic Launcher (launch rail, pneumatic box, control system), Multi-Hole Probe for relative wind measurements, operator training, and shipping. Aircraft underwent comprehensive overhaul including motor replacement, avionics upgrades (ADS-B, Remote ID, RTK), battery cycling and replacement, launcher system overhaul, component replacement, and air spring swap. Training conducted on-site at OSU.
