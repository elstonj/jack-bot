# Project 039-1 — Financial Summary

## Project Overview
- **Full Project Name:** Refurbished S2 Oklahoma State
- **Client/Agency:** Oklahoma State University (Board of Regents for Oklahoma State University and the A&M Colleges); OK Aerospace Institute (OAIRE)
- **Primary Contact:** Jamey Jacob (jdjacob@okstate.edu, 405-744-3208)
- **Contract Type:** Purchase Order for Equipment and Systems (Research/Educational Procurement)
- **Period of Performance:** December 11, 2024 – August 19, 2025
- **Project Status:** **ARCHIVED/COMPLETED** — All deliverables completed successfully; project delivered and operator training concluded.

**Scope Description:**
Complete refurbishment of an S2 UAS flight system with pneumatic launcher and multi-hole probe for meteorological observations. Work included motor replacement, avionics upgrades (ADS-B, Remote ID, RTK), battery cycling and replacement, launcher system overhaul, component replacement, and operator training. Aircraft delivered March 14, 2025; training completed August 19, 2025.
