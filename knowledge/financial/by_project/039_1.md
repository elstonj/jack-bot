# Project 039-1 — Financial Summary

## Project Overview
- **Full Project Name:** Refurbished S2 Oklahoma State
- **Client/Agency:** Oklahoma State University (Board of Regents for Oklahoma State University and the A&M Colleges); OK Aerospace Institute (OAIRE)
- **Primary Contact:** Jamey Jacob, OK Aerospace Institute, Tulsa, OK (jdjacob@okstate.edu, 405-744-3208)
- **Contract Type:** Purchase Order for equipment and systems (research/educational procurement)
- **Period of Performance:** PO issued 12/11/2024; delivery target March 2025; freight picked up 03/14/2025
- **Project Status:** **ARCHIVED / COMPLETE** (marked complete in Asana on 10/21/2026)

**Scope Description:**  
Supply and delivery of one (1) refurbished S2 UAS Flight System with Pneumatic Launcher and Multi-Hole Probe for meteorological observation. The system includes SwiftCore™ FMS, SwiftTab™ Android interface, Futaba 14SG Handset, SwiftStation™ RTK Ground Control Unit, toolkit, tripod, battery, charger, and hard case, with 12-month manufacturer defect warranty and 2-year software warranty. Includes pneumatic launcher rail, control system, and multi-hole probe for relative wind measurements. A $10,000 discount was applied to the refurbished S2 service.
