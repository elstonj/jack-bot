# Project 039-1 — Financial Summary

## Project Overview
- **Full Project Name:** Refurbished S2 Oklahoma State
- **Client/Agency:** Oklahoma State University, Board of Regents for Oklahoma State University and the A&M Colleges
- **Contract Type:** Purchase Order (Equipment/Systems Sale)
- **Period of Performance:** December 11, 2024 (PO receipt) – October 21, 2025 (project completion/archival)
- **Brief Description of Scope:**
  Complete overhaul and refurbishment of S2 UAS Flight System with pneumatic launcher and multi-hole probe. Work included motor replacement, avionics upgrades (ADS-B, Remote ID, RTK), battery cycling and replacement, launcher system overhaul, component replacement (hinges, connectors, foam, batteries), air spring swap, and operator training delivery at Oklahoma State University.
