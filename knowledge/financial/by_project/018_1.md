# Project 018-1 — Financial Summary

## Project Overview
- **Full Project Name:** Murphy's Pond CH4 Monitoring
- **Client/Agency:** Murray State University (Dr. Bassil El Masri, Department of Geosciences)
- **Contract Type:** Commercial Service Contract for drone-based greenhouse gas measurement collection
- **Period of Performance:** Field campaigns scheduled May, July, August 2026; funding expires **December 31, 2026**
- **Brief Description:** Collection of CH₄, CO₂, and H₂O measurements using Black Swift S2 VTOL aircraft over a 5 km × 5 km area above Murphy's Pond, Hickman County, Kentucky. Project includes three flight campaigns, aircraft rental (S0 VTOL), payload configuration (FLIR thermal + methane sensor), battery delivery, and data processing/flux mapping analysis.
