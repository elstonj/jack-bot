# Project 018-1 — Financial Summary

## Project Overview
- **Full Project Name:** Murphy's Pond CH4 Monitoring
- **Client/Agency:** Murray State University (Dr. Bassil El Masri, belmasri@murraystate.edu, 270-809-3110)
- **Contract Type:** Service contract for drone-based greenhouse gas measurement collection
- **Period of Performance:** 3–4 field campaigns in 2026 (May, July, August, and potentially September); funding expires 2026-12-31
- **Brief Description of Scope:** Collection of CH₄, CO₂, and H₂O measurements over a 5 km × 5 km area above Murphy's Pond, Hickman County, Kentucky using Black Swift S2 UAS platform. Scope includes flight operations, payload engineering, data processing, and flux map generation (via Atmofacts subcontractor).
