# Project 018-1 — Financial Summary

## Project Overview
- **Full Project Name:** Murphy's Pond CH4 Monitoring
- **Client/Agency:** Murray State University (Dr. Bassil El Masri, Principal Investigator)
- **Contract Type:** Service contract for drone-based greenhouse gas measurement collection
- **Period of Performance:** Funding expires 2026-12-31; field campaigns scheduled May, July, August 2026
- **Brief Description of Scope:** Collection of CH₄, CO₂, and H₂O measurements over a 5 km × 5 km area above Murphy's Pond, Hickman County, KY using Black Swift S2 fixed-wing UAS. Three field flights completed/planned (Flights #1–#3 confirmed; Flight #4 funding pending). Research focus is methane emissions from wetlands and bottomland hardwood forests using remote sensing to upscale site measurements to larger geographic areas.
