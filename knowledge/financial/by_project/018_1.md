# Project 018-1 — Financial Summary

## Project Overview
- **Full Project Name:** Murphy's Pond CH4 Monitoring
- **Client/Agency:** Murray State University (Dr. Bassil El Masri, Procurement Services)
- **Contract Type:** Service contract for drone-based greenhouse gas measurement collection
- **Period of Performance:** May 2026 – December 31, 2026 (funding expiration; field campaigns scheduled May, July, August 2026)
- **Brief Description of Scope:** Collection of CH₄, CO₂, and H₂O measurements over 5 km × 5 km area above Murphy's Pond, Hickman County, KY using fixed-wing UAS (S2 platform). Three field flights planned (Flights #1, #2, #3 completed/confirmed; Flight #4 funding contingent). Includes flight operations, data processing, remote sensing analysis, and deliverable maps.
