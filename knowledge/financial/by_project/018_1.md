# Project 018-1 — Financial Summary

## Project Overview
- **Full Project Name:** Murphy's Pond CH₄ Monitoring
- **Client/Agency:** Murray State University (Dr. Bassil El Masri, Principal Contact)
- **Contract Type:** Service contract for drone-based greenhouse gas measurement collection
- **Period of Performance:** May–December 2026 (funding expires 2026-12-31); field campaigns conducted Nov 2025, Dec 2025, Jul 2026
- **Brief Description of Scope:** Collection of CH₄, CO₂, and H₂O measurements via Black Swift S2 UAS over a 5 km × 5 km area above Murphy's Pond, Hickman County, Kentucky. Originally planned for 3 field flights (Flights #1–#3); Flight #4 addition (~$24.5K) approved via SOW modification (2026-07-09) but **postponed indefinitely as of 2026-07-22**.
