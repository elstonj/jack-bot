# Project 200-10 — Financial Summary

## Project Overview
- **Full Project Name:** 2024-25 Aeropod (AREN) — AEROKATS and ROVER Education Network
- **Client/Agency:** NASA Science Mission Directorate (Science Activation)
- **Contract Type:** Cooperative Agreement / Science Activation Project (NNX16AB95A)
- **Period of Performance:** 2024–March 2025 (funded through March 2025; project marked complete March 10, 2025)
- **Brief Description of Scope:** Commercialization and design refinement of Black Swift Technologies' Aeropod atmospheric sensing platform, including fin design optimization, particle sensor integration (transition from Atmotube Pro to Sensirion SEN55), weather instrument evaluation, and educational kit development. Project also included TerraROVER platform assembly, PocketLab weather systems distribution, and commercialization strategy discussions.
