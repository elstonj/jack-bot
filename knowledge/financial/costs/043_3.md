## Indirect Costs Assessment

**Contract Type:** Firm Fixed Price purchase order, government-funded (DISA/Wireless/SATCOM/Army Programs via By Light)

**Indirect Rate Applicability:**
- Government contracts typically require fringe (29.28%) + overhead (46.67%) markup on direct labor
- However: This is an **FFP contract with embedded costs**; fringe/overhead should already be baked into the $126,629 lump sum
- **Decision:** Do NOT apply additional indirects to the $10,745 Toggl-reconstructed labor, as it represents only tracked *time*, not BST's full cost allocation
- If this project were cost-plus, indirects would be: $10,745 × (29.28% + 46.67%) = $10,745 × 75.95% = **$8,163.28**

**Fully Loaded Labor (if cost-plus):** $10,745.00 + $8,163.28 = **$18,908.28**

**Fully Loaded Labor (FFP contract as bid):** $10,745 embedded within $126,629 FFP total
