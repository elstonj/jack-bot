## Executive Summary
This is a draft procurement specification and SOW for the supply of equipment and services supporting the Royal Navy/Lockheed Martin RAVEN UAS programme. The document establishes quality, configuration management, and testing requirements for a subcontractor, with detailed deliverable specifications and compliance frameworks.

## Technical Approach
The document defines a structured engineering and manufacturing approach including:
- Configuration Management (CM) with baseline identification and configuration control
- Quality Assurance with FAI (First Article Inspection), Certificate of Conformity, and End Item Data Package requirements
- Factory Acceptance Test (FAT) and Site Acceptance Test (SAT) processes
- Design documentation package including drawings, user manuals, and connection schematics
- Test reporting with entry/exit criteria and requirements traceability

## Products & Capabilities Described
**RAVEN Unmanned Air System** (primary deliverable)
- A UAS system to be supplied with complete technical documentation and quality assurance
- Composed of Configured Items (CIs) including hardware and software
- Includes Equipment Rack with electrical connections and external data interfaces
- Subject to first article inspection and acceptance testing

## Deliverables (SDRLs) Specified

1. **SDRL-Q003**: Certificate of Conformity
   - Formal compliance certification per DEFCON 627
   - Must include contractor details, contract/PO number, approved concessions, NSN, part numbers, serial numbers, and authorized signature

2. **SDRL-Q004**: First Article Inspection Report
   - Technical examination to verify manufacturing compliance
   - Must include completed checklists, dimensional data, configuration identifiers, and defect/corrective action records

3. **SDRL-Q008**: End Item Data Package
   - Accompanies hardware shipment
   - References ABL, FAI report, and Certificate of Conformance
   - Can substitute for EIDP if CoC fulfills all EIDP requirements

4. **SDRL-CM004**: Configured Items List
   - Complete list of all CIs with structure and characteristics
   - Per DEF STAN 05-057 Issue 8

5. **SDRL-CM005**: As-Built List
   - Final configuration identification for each serialized CI at delivery
   - Can be delivered with CoC or as part of EIDP

6. **SDRL-E007**: Design Drawing and Data Set
   - Per DEF STAN 05-010 Part 2 Issue 8
   - Includes product datasheets, user manuals, connection schematics for equipment rack
   - Electrical connections, power supply, data connection points, installation details
   - Master record index

7. **SDRL-T012**: Test Report
   - Test briefs and debrief for acceptance
   - "As-run" test procedures with results
   - Requirements summary with pass/fail/blocked status
