## Executive Summary
This is a draft procurement specification and statement of work for the RAVEN Unmanned Air System (UAS) programme, establishing requirements for Black Swift Technologies to design, manufacture, and deliver UAS equipment to Lockheed Martin UK/Royal Navy. The document defines engineering, quality assurance, configuration management, testing, training, and sustainment requirements with detailed delivery specifications (SDRLs) and acceptance criteria.

## Technical Approach

### Manufacturing & Engineering Requirements (SOW-1 through SOW-5)
- **SOW-1**: Manufacture and delivery of UAS variants (variants to be defined at later stage)
- **SOW-2**: Design changes required: UAV flight path modifications; operation without GPS/retransmission (rebro) capability
- **SOW-3**: Integration support for radios
- **SOW-4**: Design and supply data pack per SDRL-E007
- **SOW-5**: Supply Bill of Materials (BOM) for UAS and supplier-defined part-numbered items

### Configuration Management (SOW-6 through SOW-8)
- Compliance with DEF STAN 05-057 Issue 8 or equivalent standard
- Establish Functional, Design (Allocated), and Product baselines
- Define Configuration Items (CIs) and baselines in SDRL-CM004

### Quality Assurance (SOW-9 through SOW-20)
- **ISO 9001:2015 accreditation** (or equivalent) required throughout contract lifecycle
- Counterfeit parts prevention per DEF STAN 05-135
- First Article Inspection (FAI) with 10 working days advance notice
- Certificate of Conformity (CoC) per delivery
- End Item Data Package (EIDP) for each product delivered
- As-Built List (ABL) documenting final "as-built" configuration

### Testing (SOW-21 through SOW-25)
- **Factory Acceptance Test (FAT)**: Performed at supplier premises; results documented in SDRL-T012
- **Delivery**: To Global Sustainment United Kingdom Logistics Operation Centre (GSUKLOC), Lockheed Martin UK, Unit 1, Langstone Park, Havant, Hampshire PO9 1SA
- **Site Acceptance Test (SAT)**: Post-shipping/assembly verification of correct system operation; supplier responsible for correcting discrepancies

### Support & Sustainment (SOW-26 through SOW-29)
- Training delivery at supplier site with training materials (SDRL-TBC)
- In-country support for customer trials
- Technical documentation for operation and maintenance (SDRL-L040) in structured format
- Potential spares and repairs pack in-country
- Remote technical support during UAS trials

## Configuration Management & Documentation Deliverables

| SDRL Code | Title | Purpose |
|-----------|-------|---------|
| **SDRL-Q003** | Certificate of Conformity | Formal certification that delivered product conforms to design specification; includes contractor details, part numbers, serial numbers, approved concessions, signed compliance statement |
| **SDRL-Q004** | First Article Inspection Report | Technical examination verifying item conforms to manufacturing requirements, workmanship, configuration; includes measurement data, dimensional compliance, configuration identifiers, defect data |
| **SDRL-Q008** | End Item Data Package | Accompanies each end item shipment; references ABL and FAI report; can be fulfilled by tailored CoC |
| **SDRL-CM004** | Configured Items (CI) List | Lists all CIs with structure, characteristics, part numbers, manufacturers, nomenclature, LCNs, subcontractor details, NATO stock numbers |
| **SDRL-CM005** | As-Built List (ABL) | Final configuration identification of serialized CIs at delivery; includes part/serial numbers, non-conformances, drawing revisions, embodiment data, assembly references |
| **SDRL-E007** | Design Drawing & Data Set | Complete design documentation: product data sheets, user manuals, connection schemes/ICDs, equipment installation details, master record index |
| **SDRL-T012** | Test Report | FAT and SAT results: test briefs, debriefs, as-run procedures, requirements summary (Pass/Fail/Blocked) |
